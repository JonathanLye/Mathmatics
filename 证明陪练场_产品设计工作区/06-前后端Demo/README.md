### 六层各自干什么（学生视角一句话）

1. **前置知识点**（专业+高中）：先核对定义/定理，忘了可以调取知识点卡；
2. **题目解析**（你拆，AI 查漏）：四栏写清「要证什么 / 几件事 / 关键词与量词 / 可能用到的知识点」；
3. **详细步骤**（一步一依据）：每步写「结论/操作 + 依据」再提交，AI 只指第一处可疑、按 L0–L4 给最小提示；
4. **完整讲解**（你讲，AI 核对）：**由学生把整道题讲一遍**，AI 按「目标/结构/关键步骤/依据/结论」五项核对缺口，**不提供标准讲解**（这是 v2 红线最关键的一层）；
5. **同类题**（换题再做）：做一道同知识点变式题，只判对错 + 一条追问；
6. **总结**（知识点/重难点/步骤）：学生写三栏，AI 只校正表述、给掌握度。

## 3. 学生端 10 节点演示路径（v1 兼容路径；v2 六层演示以第 0.5 节为准）

固定题目：判断级数 ∑(−1)^(n−1)/√n 的收敛性；若收敛，是条件收敛还是绝对收敛？证明你的结论。
（白话：一串正负交替的数加起来会不会稳住；「条件收敛」指带上正负号才收敛、去掉负号就发散。）

> **重要**：Demo 只完整开放这一道题（`p-cond-series`，界面显示「第 2 题」）；其余 11 道可浏览题面，点「开始」会返回 409「该题暂未开放完整脚本」——这是演示范围的边界，不是 bug。
> 节点 5、7 是特殊节点：**直接提交会返回 409 引导到对应接口**（提示阶梯 / 要答案），这是状态机设计。

| 节点 | 你点什么 | 期望看到 | 后端发生了什么 |
|---|---|---|---|
| 1 读题 | S0 点「演示登录」→ S1 → S2 选「第 2 题」→ 输入「要证这个级数收敛，还要判断它是条件收敛还是绝对收敛」提交；再按提示回答「条件收敛的定义」 | 第 1 轮：AI 追问条件收敛定义；第 2 轮：核对定义后问「要证几件事」 | POST `/step`；节点 1 共 2 轮，答完推进到节点 2 |
| 2 拆题 | 输入「两件：先证原级数收敛；再证绝对值级数 ∑1/√n 发散」提交 | 肯定 + 追问先攻哪件 | 节点 2 共 1 轮，推进到节点 3（P3） |
| 3 第 1 步 | 输入「u_n=1/√n 随 n 增大而变小，因为分母越来越大」提交 | 只指第一处可疑：缺 n 与 n+1 的不等式 | 节点 3；诊断 `type=缺不等式` |
| 4 第 2 步 | 输入「1/√(n+1) < 1/√n，因为 n+1 > n」提交 | 通过 + 追问极限为 0 的依据 | 节点 4；写入草稿第 1 步 |
| 5 卡住 | **直接点「提示」→ 选 L2**（此时直接提交会被 409 引导） | 只给方向，不给式子；响应带 `state.used/unlocked/guard` | POST `/hint`；预算 L2-1；自动推进到节点 6 |
| 6 第 3 步 | 两轮：①输入「因为 lim n^{1/2}=+∞，所以 lim 1/√n=0」②输入「由莱布尼茨判别法，这个交错级数收敛」 | 肯定 + 让收成莱布尼茨结论 + 转向绝对值级数 | 节点 6 共 2 轮，推进到节点 7 |
| 7 要答案 | **直接点「我卡住了，想直接看答案」**（提交会被 409 引导） | 三段式拒绝（接住→规则→替代动作四选一） | POST `/answer-request`；`refusals+1`；推进到节点 8；永不返回证明 |
| 8 看不懂 | 两轮：①输入「∑1/√n 是 p 级数，p=1/2，可规则我忘了，看不懂」②输入「p=1/2 ≤ 1，所以 ∑1/√n 发散」 | 小白解释卡：类比 + 与本题无关的最小例子 + 严格定义；再收口 | `/xiaobai`（≤2 次）+ `/step`；推进到节点 9 |
| 9 终稿 | 交终稿（可点「填入示例终稿」）→ 看 5 条问句覆盖表 → 填五问复盘 | 覆盖 5/5 才可复盘；复盘卡 5 问都可填 | POST `/final` → `/review`；事件写入 |
| 10 变式 | 提交变式题答案「绝对收敛，因为 1/n² 是 p=2 的 p 级数」 | 只给对错 + 一句反馈；完成页出现掌握度与独立性档位 | POST `/variant`；attempt 结束，判定 independence |

红线自检：全程 AI 对话区不出现完整证明、最终答案、「证毕/证明如下/综上/答案是」；终稿只出现在学生草稿区。

## 6. mock 与真实模型现状（`DEEPSEEK_API_KEY`）

**默认：mock**（不设任何环境变量）。后端按题目脚本 + 轻量诊断规则返回三段式，稳定、可离线、演示不会因网络失败。

**真实模型现状（v2 未接线，答辩不要承诺）**：

- v2 的 `server/server.mjs` **没有调用真实模型**；设置 `DEEPSEEK_API_KEY` 目前只会让 `/api/health.mode` 显示 `deepseek`，实际仍走 mock。
- 接入方式（后续任务）：在 `ai.mjs` 判定之后、guard 之前调用 DeepSeek（model `deepseek-chat`，8s 超时），输出先过 guard，失败回退 mock；提示阶梯/拒绝/小白解释仍走预置脚本，保证演示稳定。
- 真实模型不会改变教师端种子数字；演示数据仍来自 db.json。
- **不要把 key 写进代码、README 或提交到仓库。**

## 7. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 双击没反应/黑窗口一闪而过 | Node.js 未安装 | 安装 Node.js 18+（<https://nodejs.org/>），`node -v` 能看到版本；或让项目组提供内置运行时 |
| 端口被占用（EADDRINUSE） | 8787 已被别的程序占用 | 换端口：CMD `set PORT=8788` → `start-demo.cmd`；PowerShell `$env:PORT="8788"` |
| 浏览器打不开 / 连不上 | 服务没起来，或开了代理 | 先访问 <http://127.0.0.1:8787/api/health>；确认没走代理；用 127.0.0.1 而非 localhost |
| 页面白屏/还是旧版 | 浏览器缓存，或后端未启动 | 先访问 http://127.0.0.1:8787/api/health 确认后端；再 `Ctrl + F5` 强制刷新 |
| 数字/推进不对 | 演示中改过数据 | 后端面板点「重置数据」，或停服务后删除 `server/data/db.json` 再启动（自动 seed） |
| 选其他题点「开始」报错 | 可能是层门禁/状态错误，或题目未发布 | v2 所有已发布题都可进入六层；409 时按提示先完成当前层，或重置数据重试 |
| API 返回 401 | 没登录 / token 失效 | 重启服务后 token 在内存里失效，需重新登录；调用时带 `Authorization: Bearer <token>` |
| 提示按钮点不动/409/429 | 等级未解锁或预算用尽 | **设计行为**：409=先提交一次/先用上一级；429=预算用完，走软着陆（L0/定义卡/换题/转教师） |
| 节点 5/7 提交报 409 | 这两个节点是「卡住」「要答案」专用节点 | 正常：按提示分别点「提示阶梯」和「我要答案」 |
| CSV 打开乱码 / 下载失败 | Excel 编码问题；或 PowerShell 非交互下载报错 | 导出为 UTF-8（带 BOM）；用 Excel「数据→从文本」按 UTF-8 导入；脚本下载加 `-UseBasicParsing` 或用 `curl.exe -o` |
| 想换演示题 | 只完整开放第 2 题 | 改 `server/seed.mjs` 的脚本或另建题目；不建议现场改 |

## 10. 已知限制（评审请知悉）

- 单进程、JSON 文件存储，不支持并发多实例；重启不丢数据，但删了 db.json 就重新 seed；事件上限 4000 条。
- 登录为演示态：邀请码 `MATH-A-2026` + 任意非空学号；`studentId=demo` 直接进；token 存内存，重启需重登。
- 教师端接口演示版不强制鉴权；生产版需加登录与权限。
- 只完整开放 1 道题（第 2 题 · 交错级数与条件收敛）；其余 11 道有题面/要点/提示，用于演示选题与出题量。
- AI 默认 mock；真实模型为可选且仅在提交一步时生效；不稳定时自动回退 mock。
- 题库审核、复测、家长端等不在本 Demo 范围（见 `../03-产品设计` 的范围表）。
