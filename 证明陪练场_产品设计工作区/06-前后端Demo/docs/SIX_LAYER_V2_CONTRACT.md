# 六层引导工作台 v2 · 契约（唯一事实源）

> 版本 v2.0 ｜ 2026-10-31 ｜ 维护：Lead
> 背景：用户指出 v1 两个问题：① 界面只有 P1–P6 证明流程，看不到第一版的六层（前置知识点 / 题目解析 / 详细步骤 / 完整讲解 / 同类题 / 总结）；② 学生不知道在哪里提交答案，AI 像「在一旁聊天」，提示要自己找。
> 本契约定义 v2 六层引导工作台：六层全部显式可见、每层学生先做、AI 主动给下一步指令和最小提示、提交入口唯一且明显。

---

## 0. 核心原则

1. 六层是主流程，不是隐藏内容：顶部 stepper 必须出现六层原名；每层有独立任务卡、输入区、提交按钮、完成状态。
2. 学生先做，AI 后说：每层的 AI 反馈都发生在学生提交之后；AI 不替学生产出六层内容。
3. AI 是教练，不是旁白：右侧「AI 教练」常驻，明确写「现在请你做：…」+「下一步」；提示按钮常驻，不需要学生找。
4. 主动提示：同一处连续失败 2 次，后端返回 proactive offer，前端在 AI 教练面板弹出「要不要给你一个方向提示？（不会给答案）」按钮。
5. 提交入口唯一：每层主区域有一个大输入 + 一个主按钮（提交我的理解 / 提交解析 / 提交这一步 / 提交完整讲解 / 提交变式题 / 提交总结）；提交后内容进入「我的记录」，AI 反馈在右侧。
6. 红线不变：AI 不输出完整证明/最终答案/可抄推导链/编号骨架；六层内容都由学生产出或学生主动调取（知识点卡、题意重述、定义卡）。

## 1. 六层定义（UI 名字与任务）

| 层 | UI 名称 | 副标题 | 学生任务 | AI 只做什么 | 完成判据 |
|---|---|---|---|---|---|
| 1 | 前置知识点 | 专业 + 高中 | 回答记得/忘了/没学过；核对定义；必要时调取知识点卡 | 提问、给知识点卡（专业版 + 高中版）、判定复述 | 复述通过或 2 次后带病前进 |
| 2 | 题目解析 | 你拆，AI 查漏 | 填：要证什么 / 几件事 / 关键词 / 可能用到的知识点 | 逐项查漏、给「高中版题意」（只换说法，不给解法） | 四栏无缺项或补到通过 |
| 3 | 详细步骤 | 一步一依据 | 每步写「结论/操作 + 依据」，提交；卡住点提示 | 只指第一处可疑、追问依据、L0–L4 提示、主动 offer | 覆盖 ≥80% 且学生点「写完了」 |
| 4 | 完整讲解 | 你讲，AI 核对 | 像给同学讲题一样，完整讲一遍（目标/结构/关键步骤/依据/结论） | 对照关键步骤给缺口清单与追问，不给标准讲解 | 讲解覆盖 ≥80% |
| 5 | 同类题 | 换题再做 | 做一道同知识点、不同题面的题，写出答案/关键步骤 | 只判对错 + 一条追问，不给解法 | 答案正确 |
| 6 | 总结 | 知识点/重难点/步骤 | 用自己的话写：知识点、重点难点、解题步骤 | 校正表述、生成总结卡、给掌握度 | 三栏完成且 AI 校正 |

> 「完整讲解」在旧版里是 AI 讲完整题，违反红线。v2 明确改为学生讲、AI 核对；这是六层与红线的结合点，UI 上要写清楚一句：「完整讲解由你完成，AI 只核对，不提供标准讲解」。

## 2. 页面布局（学生端 S3）

桌面（≥1024px）：

~~~ text
┌──────────────────────────────────────────────────────────────┐
│ 顶栏：证明陪练场 | ① 学生端 ② 教师端 ③ 后端与数据 ④ 说明       │
├──────────────────────────────────────────────────────────────┤
│ 题目卡（题面 + 知识点标签 + 预计时间 + 保存返回）              │
├──────────────────────────────────────────────────────────────┤
│ 六层 stepper：① 前置知识点 ② 题目解析 ③ 详细步骤 ④ 完整讲解 ⑤ 同类题 ⑥ 总结 │
├──────────────────────────────────┬───────────────────────────┤
│ 左 60%：当前任务卡               │ 右 40%：AI 教练            │
│  · 层标题 + 一句任务说明         │  · 现在请你做：…（常驻）   │
│  · 输入区（大）                  │  · 最新反馈（三段式）      │
│  · 主提交按钮                    │  · 提示按钮组 L0–L4（常驻）│
│  · 我的记录 / 我的证明（历史）   │  · 「我要答案」拒绝入口    │
│                                  │  · 主动 offer 气泡         │
├──────────────────────────────────┴───────────────────────────┤
│ 手机端：任务卡 + 输入区堆叠；底部 sticky「提交」+「卡住了？」   │
└──────────────────────────────────────────────────────────────┘
~~~

明确要求：
- 提交按钮必须在输入区正下方，文案为「提交这一步 / 提交我的理解 / 提交解析 / 提交完整讲解 / 提交变式题 / 提交总结」，不能藏在聊天框里。
- 「我的证明」列表显示每个已提交步骤（结论 + 依据 + 状态：通过/待改/被标疑点 + AI 一句话反馈）。
- AI 教练顶部固定一句「现在请你做：…」，随层/步骤变化；学生不需要问「然后呢」。
- 提示按钮常驻：L0/L1/L2/L3/L4 + 剩余次数；锁定/用完状态清楚；点击直接调 /hint。
- 「我要答案」按钮常驻，点击调 /answer-request，显示三段式拒绝。
- 主动 offer：后端返回 proactive 时，AI 教练显示高亮气泡 + 一个按钮「给我一个方向提示（L2）」，点击等于 /hint L2。

## 4. API（v2 新增/调整；其余保留）

鉴权、错误格式、预算/闸门规则沿用 v1。所有学生端响应需带 state。

| 层 | 方法/路径 | 请求 | 响应 |
|---|---|---|---|
| — | GET /api/attempts/:id | — | {attempt, problem, state} |
| — | POST /api/attempts | {problemId} | {attemptId, problem, state}；state.layer=1 |
| — | GET /api/problems/:id/knowledge | — | 知识点卡（professional/plain/checkQuestion），不含解法 |
| 1 | POST /api/attempts/:id/knowledge | {action:"answer", answer:"…"} 或 {action:"request-card"} | {passed, feedback, state} |
| 2 | POST /api/attempts/:id/parse | {goal, parts, keywords, tools} | {feedback:[{field,status,message}], passed, state, plainRestatement} |
| 3 | POST /api/attempts/:id/step | {conclusion, evidence} | {ai:{judge,hint,ask,tag}, step, state, proactive} |
| 3 | POST /api/attempts/:id/hint | {level:"L0".."L4"} | 同 v1，额外返回 plain（这一步在干什么，小白版） |
| 3 | POST /api/attempts/:id/answer-request | {} | 同 v1 三段式拒绝 |
| 3 | POST /api/attempts/:id/final | {text} | {coverage, passed, state}；passed → layer=4 |
| 4 | POST /api/attempts/:id/explain | {text} | {feedback:[{criterion,status,message}], passed, state}；passed → layer=5 |
| 5 | GET /api/attempts/:id/variant | — | {variant:{title,stem}} |
| 5 | POST /api/attempts/:id/variant | {answer} | {result:{correct,feedback}, state}；correct → layer=6 |
| 6 | POST /api/attempts/:id/summary | {knowledge, difficulty, steps} | {feedback, passed, card, mastery, independence, state}；完成后 finishedAt |

关键规则：
- /step 的 proactive：同一层/同一步连续失败 ≥2 次时返回 {offer:true, level:"L2", text:"要不要先给一个方向提示？不会给答案。"}；否则 null。
- /hint 的 plain 只解释「这一步在做什么/为什么需要它」，不得给具体结论或表达式。
- /explain 的 feedback 固定五项：目标、结构、关键步骤、依据、结论；缺哪项说哪项，不给标准讲解。
- /summary 检查三栏非空 + 是否出现「条件收敛/莱布尼茨/p级数」等关键词；不给标准总结。
- 每层通过时把 layerStatus 当前层置 done、下一层 active；state.layer 前进。

## 5. 每层文案（可直接用）

### L1
- 标题：第 1 层 · 前置知识点
- AI 指令：先别急着写证明。你记得「条件收敛」和「莱布尼茨判别法」吗？先选一个。
- 按钮：我记得，直接核对 / 我忘了，看知识点卡 / 完全没学过，只看高中版
- 输入：用自己的话说：条件收敛和收敛有什么区别？
- 提交：提交我的理解
- 知识点卡 tabs：专业知识点 / 高中水平解读
- 通过后：进入第 2 层 · 题目解析

### L2
- 标题：第 2 层 · 题目解析（你拆，AI 查漏）
- 四栏：要证什么 / 要证几件事 / 关键词与量词 / 可能用到的知识点
- 按钮：提交我的解析 / 看高中版题意（只换说法）
- AI 反馈：逐项 ✓/缺/需改，不给解法
- 通过后：进入第 3 层 · 详细步骤

### L3
- 标题：第 3 层 · 详细步骤（一步一依据）
- 指令：现在写第 1 步：先证单调递减。写「结论/操作 + 依据」，然后点提交。
- 输入：结论/操作 + 依据（两个输入框）
- 按钮：提交这一步
- 我的证明：列表显示每步 + 状态 + AI 一句话
- 提示区：L0-L4 按钮 + 剩余次数 + 我要答案
- 主动 offer 气泡
- 通过后：写完了，进入第 4 层 · 完整讲解

### L4
- 标题：第 4 层 · 完整讲解（你讲，AI 核对）
- 说明：完整讲解由你完成，AI 只核对缺口，不提供标准讲解。
- 输入：像给同学讲题一样，把整道题讲一遍：要证什么、分几段、每段依据、结论。
- 按钮：提交完整讲解
- 反馈：五项 checklist（目标/结构/关键步骤/依据/结论）
- 通过后：进入第 5 层 · 同类题

### L5
- 标题：第 5 层 · 同类题（换题再做）
- 题面：∑(−1)^{n−1}/n²，判断收敛性并说明条件/绝对收敛
- 输入：你的答案/关键步骤
- 按钮：提交变式题
- 反馈：对/错 + 一条追问
- 通过后：进入第 6 层 · 总结

### L6
- 标题：第 6 层 · 总结（知识点 / 重难点 / 步骤）
- 三栏：我学到的知识点 / 最容易错的重难点 / 下次的解题步骤
- 按钮：提交总结
- 反馈：校正 + 总结卡 + 掌握度；完成

## 6. 验收（Lead 会跑）

1. 打开 ?demo=1：六层 stepper 可见，当前第 1 层高亮，AI 教练写「现在请你做：…」。
2. 第 1 层：可点「我忘了」看知识点卡（专业/高中两 tab）；提交复述后进入第 2 层。
3. 第 2 层：四栏 + 提交；AI 逐项查漏；通过进入第 3 层。
4. 第 3 层：输入 + 提交按钮明显；提交后步骤进入「我的证明」；AI 反馈自动出现；连续失败 2 次出现主动提示 offer；提示按钮常驻且显示剩余次数；我要答案被拒绝。
5. 第 4 层：学生讲解输入 + 五项 checklist；通过进入第 5 层。
6. 第 5 层：变式题 + 提交；通过进入第 6 层。
7. 第 6 层：三栏 + 提交；出现总结卡与掌握度；六层全部 done。
8. 全流程 AI 区无完整证明/最终答案；/api/problems/:id 不含 keySteps/hints/referenceProof。
9. 390px 下：stepper 可横向滚动或换行，提交按钮 sticky 可见，无横向溢出。
10. 后端 e2e：新增六层流程断言 ≥20 条，全 PASS。
