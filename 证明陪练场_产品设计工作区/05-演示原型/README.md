# 证明陪练场 · 可点击原型 v1（05-演示原型 · 离线版）

> ⚠️ 本页是 v1 离线流程原型。六层引导优化版（推荐演示）在 [../06-前后端Demo/README.md](../06-前后端Demo/README.md)：双击 start-demo.cmd → http://127.0.0.1:8787/?demo=1

> 面向对象：老师 / 甲方 / 产品评审。目标是在 5 分钟内看懂「学生到底怎么用、AI 为什么不会替学生写证明、老师看到什么」。
> 单一事实源：`../00-过程记录/02-流程与页面契约.md`（页面、状态、提示预算、10 个演示节点均以它为准）。
> 原型不接真实模型：全部 AI 回复、班级数据均为预置脚本 / mock，用浏览器打开即可。

## 1. 怎么打开

- 直接双击 `index.html`，任何现代浏览器（Chrome / Edge / Safari）都能离线打开；无 CDN、无字体、无 MathJax、无外链图片。
- 推荐窗口：桌面 1440×900；手机窄屏 390×844 已适配（见第 6 节验收记录）。
- 右上角 **「讲解模式」开关**：打开后每一屏出现黄色「🎯 设计意图」标注，并标出对应契约编号，适合边讲边看。
- 学生端演示条右侧有 **「重置演示」**，可随时从 S0 重新走一遍。
- 演示顺序建议：① 流程总览 → ② 学生端演示（按提示逐步点）→ ③ 教师端看板 → ④ 设计边界与说明。

| Tab | 内容 | 讲解要点 |

## 3. 学生端 S0–S5 快速走法（约 3 分钟）

1. **S0 登录入班**：可直接点「演示模式：一键进入」；也可保留预置邀请码 / 学号点「进入班级」。
2. **S1 今日任务**：本周必做 3 题进度、继续上次、复测提醒；点「继续作答」或「进入选题」。
3. **S2 选题**：章节 / 知识点 / 难度 / 必做筛选都会实时过滤；「第 2 题」是唯一完整开放演示的题。
4. **S3 作答主界面**：
   - 左侧是题面与「我的草稿 / 终稿」，右侧是 AI 陪练对话、提示阶梯预算、我要答案 / 看不懂；
   - 每一步点「填入示例作答」（可编辑）→「提交这一步」；AI 固定三段【判断】【提示】【提问】；
   - 第 5 节点点提示阶梯里的 **L2**（只给方向），第 7 节点发送「直接给我完整证明」→ 三段式拒绝弹窗（四选一替代动作）；
   - 第 8 节点看 **小白解释卡**（类比 + 与本题无关的最小例子 + 回到严格表述），并要求复述。
5. **S4 终稿核对**：填 / 改终稿 → 提交后出现 **5 条问句化的覆盖表**（5/5）；再复述主线、答五问复盘卡。
6. **S5 完成页**：掌握度、3–5 条规律、自检卡、变式题、复测提醒；提交变式题后出现「演示完成 10/10」。

> 红线验证点：整个过程中 AI 对话区不会出现完整证明或最终结论；学生的终稿只出现在「我的草稿 / 终稿」区域。

## 4. 10 个演示节点 ↔ 契约 §7

| 节点 | 学生动作（示例按钮） | AI 预置反应 | 页面 |
|---|---|---|---|
| 1 读题 | 说「要证收敛，还要判断条件 / 绝对」 | L0 追问「条件收敛定义是什么」 | S3 |
| 2 拆题 | 说「要证两件事」 | 肯定 + 追问先攻哪件 | S3 |
| 3 写第 1 步 | 「u_n=1/√n 递减，因为分母变大」 | 只指第一处可疑：缺 n 与 n+1 的不等式 | S3 |
| 4 写第 2 步 | 「1/√(n+1)<1/√n」 | 通过 + 追问极限为 0 的依据 | S3 |
| 5 卡住 | 提交卡点 → 打开提示阶梯 → 用 L2 | 给「n^α 极限」方向，只给方向 | S3 / S3a |
| 6 写第 3 步 | 「n^{1/2}→∞，所以 1/√n→0」 | 肯定 + 让收成莱布尼茨结论 | S3 |
| 7 要答案 | 「直接给我完整证明」 | 三段式拒绝 + 四选一替代动作 | S3 / S3b |
| 8 绝对收敛 | 「∑1/√n 是 p 级数，p=1/2，我忘了规则」 | 小白解释 + 回到严格表述追问 | S3 / S3c |
| 9 终稿 | 四行终稿 → 提交 | 覆盖 5/5，全问句核对 | S4 |
| 10 复盘 + 变式 | 五问复盘、3 条规律、自检卡、变式题 | 只校正表述 + 给出变式题面 | S4 / S5 |

**固定题目**：判断级数 ∑_{n=1}^{∞} (−1)^{n−1}/√n 的收敛性；若收敛，是条件收敛还是绝对收敛？证明你的结论。
（公式用 HTML 上下标与 Unicode 排版，不依赖 MathJax。）

## 5. 哪些是 mock / 哪些可交互

**mock（预置、不会真的调用）**

- 所有 AI 回复、诊断、覆盖率、掌握度 78 分、班级数据、学生过程摘要、题库审核、CSV 内容；
- 登录不校验真实邀请码 / 学号、不复测、不写数据库；导出 CSV 为浏览器本地生成的演示文件。

**真实可交互**

- 4 个 Tab、讲解模式开关、重置演示；
- S0–S5 全链路页面切换、筛选、预览、填入示例、提交、提示预算扣减、提示阶梯/拒绝/小白解释弹窗、五问复盘、规律/自检卡/变式题提交；
- 教师端：周 / 月切换、学生过程摘要弹窗、题库审核通过 / 退回、未完成名单、导出 CSV（浏览器下载）。

## 6. 验收记录（本轮自测）

- **1440×900**：流程总览、S3、S4、S5、教师端均无横向溢出、无错位。
- **390×844（真机等效）**：用 Edge CDP `Emulation.setDeviceMetricsOverride` 在 390 宽下逐屏检查：
  - `document.documentElement.scrollWidth = 390`，无横向滚动；
  - 无越界元素；Tab 自动换行（≤720px），不再被裁切；
  - 无重复 id、无 JS 报错。
- **10 节点自动走查**：从 S0 一路点击到 S5，最终状态 `page=S5, step=10, rounds=13, errs=[]`，10/10 节点全部点通。

## 7. 后续接真 AI 的改造点

1. **对话层**：把 `SCRIPT` 预置数组替换为 `POST /api/tutor/turn`，请求带题干、内部关键要点（≤5 条、禁止转述）、历史、已给提示、当前等级；响应仍强制三段式 JSON。
2. **输出校验**：在服务端加「禁用词 / 编号列表 / 双问句 / 连读能否成证明」四道校验，失败降级为 L0，前端保留本条三段落点不变。
3. **提示预算**：前端已有 `rem` / `used` 状态，直接把计数落到后端（同一题跨会话累计，防刷提示）；L3/L4 后强制复述的前端拦截保留。
4. **覆盖表**：把 `COVERAGE` 的 5 条问句和内部要点从教研录入卡读取，按学生终稿真实计算覆盖；不展示参考证明。
5. **数据与导出**：把学生每轮字段（提示等级、提示原文、诊断、预算、拒绝、小白解释、粘贴标记、用时、独立性）写入数据库；CSV 导出改为服务端生成，默认匿名账号码。
6. **教师端**：KPI / 卡点 Top5 / 过程摘要 / 审核队列接口化；本轮只保留页面结构与字段口径。
7. **登录与班级**：邀请码 + 学号换成真实班级服务；复测提醒接消息通道（先站内）。
8. **口径待定**：D1（能否明说对错）、D2（L1/L2 限次）等按契约默认先做，接真模型前由罗老师确认。

## 9. v1.2 迭代记录（按走查反馈，2026-10-31）

- **M1 提示阶梯最低解锁（P0）**：L0 随时可用；L1 需当前节点提交 ≥1 次；L2 需 L1 已用或连续失败 2 次；L3 需 L2 已用或连续 3 次；L4 需 L3 已用或连续 4 次。未解锁按钮置灰、显示原因，点击提示「先试试上一级，或再提交一次」；脚本节点 5 预置「连续失败 1 次」，提交卡点后达到 2 次，因此 L2 可点、L3/L4 仍锁定（走查数值：step1 解锁 1 / 锁定 4；step5 解锁 L0/L1/L2、锁定 L3/L4）。
