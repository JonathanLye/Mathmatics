学生到底怎么用：卡住 → 被追问 → 自己写完

AI 不写证明、不给最终答案、不写能直接抄的推导链；它只指出第一处可疑步骤，按 L0–L4 给最小提示。教师看到的是过程数据，不是分数。

原型 · 不接真实模型
1. 先走一遍学生端点「② 学生端演示」→ 每一步点「填入示例作答」→ 提交，10 个节点约 3 分钟。
2. 看两条红线怎么被守住第 7 节点点「直接给我完整证明」，观察三段式拒绝；第 8 节点点「看不懂」看小白解释卡。
3. 再看老师看到什么「③ 教师端看板」：卡点 Top5、过程摘要、审核队列、导出 CSV（演示）。
给老师/甲方看的导航页，不进入学生真实界面。先看动线，再看学生端，最后看教师端与边界。契约 §3 / §5

三条红线（原型里必须看得见）

违反任意一条，这个产品就不成立。

RED LINE 01

不给完整证明

任何时候都不输出能连成证明的内容；AI 对话区只出现判断、提示、提问。

RED LINE 02

不给最终答案

不说「所以条件收敛」这类结论；学生要答案时走三段式拒绝。

RED LINE 03

不写可抄的推导链

一轮里不能有 ≥3 个可连成证明的逻辑步骤；禁止编号步骤、表格、证明骨架。

红线不是口号，原型里用三个可点击的位置演示：S3 的「我要答案」、S4 的覆盖表（问句）、AI 区永不出现完整证明。契约 §1 / §6 / §7

    ④ 设计边界与说明

    哪些是红线，哪些还没拍板

    这一页给老师 / 甲方核对口径；标「待确认」的项本轮按默认口径做，不阻塞原型。

    待确认项 D1–D11 见页面底部
    RED LINE 01

    不给完整证明

    AI 对话区永远不出现连贯证明；终稿只能出现在学生的草稿区，由学生自己写。

    RED LINE 02

    不给最终答案

    不说「所以条件收敛」这类结论；学生要答案时走三段式拒绝，且必须给 60 秒内可做的替代动作。

    RED LINE 03

    不写可抄的推导链

    任何一轮不得出现可连成证明的 ≥3 步推导；禁止编号步骤、表格、证明骨架、禁用收尾词。

    提示阶梯 L0–L4

    信息量逐级增加
    L0
    元认知追问 · 0 条新信息 · ≤30 字
    只问依据，不暗示对错。例：「你这一步的依据是哪条定义？」
    L1
    概念提示 · 只点名定理/定义 · ≤60 字
    例：「这题的关键是莱布尼茨判别法，它有三个条件，你逐条核对了吗？」
    L2
    方向提示 · 只给方法入口/结构 · ≤80 字
    例：「要证不绝对收敛，得看 ∑|a_n|。先判断它是哪种级数。」
    L3
    局部步骤 · 只给一步，给完立即交还 · ≤120 字
    例：「示范一步：由 lim n1/2=+∞ 得 lim 1/√n=0。下一句你补。」
    L4
    示范微步 · 1–2 行 + 交接句 + 复述要求 · ≤200 字
    例：「先示范一行：1/√(n+1)<1/√n。剩下两个条件由你补，并复述理由。」
    L5
    不存在。学生要答案时走拒绝模板；任何情况下都不得输出完整证明。

    单轮正文合计 ≤130 字（L4 示范可到 200 字）；【判断】≤25 字；【提问】恰好 1 个问句、≤40 字。

    L0–L4 的核心不是「层层加码给答案」，而是「每升一级只多给一点点信息」，并且用完后必须交还学生。契约 §6 / 说明 v1.0 §5.1

    提示预算（默认口径，待罗老师确认）

    D2
    项目上限说明
    L1≤3 次分题计，换题重计
    L2≤3 次同一错误点连续失败才升
    L3≤2 次给一步就交还，必须复述
    L4≤1 次示范 1–2 行，必须交接
    信息型合计≤9 次用尽后只能 L0 追问或转教师
    L0 追问≤6 次不计提示预算，计入轮次
    小白解释≤2 次必须回严格表述并复述
    单题轮次≤16 轮主流程，含 1 次拒绝轮
    单题用时≤25 分钟超 1.5 倍提醒休息 / 转教师
    变式题≤8 轮独立预算，不占主题预算
    预算让学生「自己先想」有时间价值：提示不是无限的，也不是免费的。契约 §6 / 说明 v1.0 §5.2

    指标口径（教师端 / 后续导出）

    过程数据，不是分数
    指标口径原型里在哪看
    完成率本周必做 3 题全部提交的人数 / 班级人数教师端 KPI ①
    未完成名单本周必做未交齐；标注最后活动时间与卡点教师端 KPI ② + 名单
    平均提示轮数每题消耗的 L1–L4 次数均值；L0 与小白解释不计入教师端 KPI ③
    卡点知识点 Top5同一知识点连续 2 轮无进展，或触发 L2 及以上提示的人数占比教师端条形图
    独立性（C1 三档）独立＝仅用 L0 追问；半独立＝使用过 L1–L2；依赖＝使用过 L3–L4 或出现粘贴标记。不合并成单一百分比。教师端 KPI ④（堆叠条）/ 学生详情
    覆盖度终稿命中内部关键要点数 / 要点总数（≥80% 通过）S4 覆盖表 / 教师端学生详情
    这套指标服务「看过程」：教师能回答「卡在哪、提示几次、是否独立」，而不是只有一个分数。契约 §8
