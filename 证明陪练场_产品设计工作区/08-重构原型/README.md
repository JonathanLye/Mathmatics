# 08 · 重构原型（v3）

```bash
node server.mjs
```

然后打开 http://127.0.0.1:8787。无外部依赖，页面不向外网发任何请求：KaTeX 在 `vendor/`，字体用系统字体。

直接双击打开 `index.html` 也能用，只是「本机编译验证」按钮需要 `server.mjs`。

**本机编译**：教师页（和学生写完后的总结页）点「本机编译验证」，`server.mjs` 用本机的 Lean 4 + mathlib 编译 `lean/*.lean`，结果显示在页面里，首次约 10 秒。Lean 项目路径默认 `~/lean-verify/proofcheck`，可用环境变量 `LEAN_PROJECT` 改。服务只监听 127.0.0.1，只编译 `lean/` 下登记的文件，不接受页面传来的任意代码。

- 两道题：ε-N 数列极限、交错级数收敛性。
- 六层骨架：定义核验 → 证明骨架 → 构造与推导 → 自检 → 迁移题 → 总结。第 1、2、4、5 层可以跳过。
- 右侧是批注栏：一次只问一个问题。提示 H0–H4 全部为教师预写，从 H2 起计透露量：每个关键步骤按它到达的最高一级计，全题 ≤2。H2 起每升一级，要求学生先再写一行、停留满 20 秒；30 秒内连点 3 次就暂停 60 秒。
- H4 示范过的那一行，学生必须在"依据"里写出它为什么成立，才算自己写出的步骤。
- 所有外发文本都经过 `gate()`，包括批注、提示、任务说明、直观卡、自检题和迁移题：只要文本里出现学生还没写出、也没计入透露量的关键步骤片段，就会被拦下。题面本身不过闸门。
- "教师"页显示过程指标，"事件"页显示只追加的事件流。

规格见 [../07-重构审计与方案/02-全新融合方案.md](../07-重构审计与方案/02-全新融合方案.md)。

## 演示模式

页面顶部的「演示」条：选一个学生场景，点「下一步」，页面自动把内容打进输入框，并高亮提交按钮，**由你手动点**才提交，走的是真实的界面逻辑。纯点击的步骤（要提示、看不懂、切教师页）也只高亮按钮。忘了点或想省事，可点「代点」。每步显示“下一步做什么”和“看点”。「自动播放」则全程自动，每步停留约 1.5 秒。演示时跳过了提示的 20 秒等待，其余门槛（先写一行再升级、连点锁定、额度）照常生效。

- 独立完成：13 步，4 个关键步骤全部自己写出，透露 0，走完整六层，最后在教师页点本机编译。
- 中档（有卡点）：23 步，定义顺序写反、N 取成 n+1、用 H0–H2，透露 0.5，总结漏要点被追问。
- 需要不断指点：27 步，搬老师施压、连点锁定、额度用满、标记求助老师。

三个场景都用 ε-N 题。

## mathlib4 对照与「问一句」（本次新增）

- 教师页底部、学生写完本题后的总结页：每个关键步骤对应的 mathlib4 定理，加 Lean 代码和本机编译按钮。
- 两份 Lean 代码已在本机用 Lean 4.35.0 + mathlib v4.35.0 编译通过，无 `sorry`、无报错。源文件在 `lean/`（`EpsN.lean`、`Series.lean`）。
- 「问一句」：词条式短答（`GLOSS`）+ “这一行”专答 + 预设问题按钮，全部走 `gate()`。无关问题只回一句。演示版没有接大模型。
- 修改前的版本：`index.v3.bak.html`。

## 原型的局限

- 级数题直观卡的边界例子提到"通项不趋于 0 所以发散"，与关键步骤 K2 的条件有关。这算定义层面的内容，但需要教师审核时明确确认。

- 归类器是正则匹配，只用来演示交互；正式版要换成 LLM 输出的结构化 JSON 加置信度，并用约 60 条人工标注的学生步骤验证。
- 迁移题只记录作答，不走完整流程。
- 公式输入用的是 Unicode 符号键位行，正式版换成 MathLive。
