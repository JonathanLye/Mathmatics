## 0. 一页纸

- **一条主线**：入班（S0）→ 今日任务（S1）→ 选题（S2）→ 读题/拆题/分步写证明（S3，核心）→ 终稿核对 + 五问复盘（S4）→ 迁移总结（S5）→ 结束。
- **一个心脏**：S3 里的「写一步 + 写依据 → 提交 → 只指出第一处可疑 → 追问依据 → 不够才升提示 → 学生重写」循环，单题最多 16 轮、25 分钟。
- **一条红线**：全程不出现完整证明、最终答案、可连成证明的 ≥3 步推导。
- **一张网**：13 条异常分支都有固定处理；每题每轮落 28 个数据字段；17 条 Given/When/Then 验收标准可直接转测试用例。

## 1. 角色、范围与名词

### 1.1 本轮范围内的角色

| 角色 | 在本 PRD 里的动作 |
|---|---|
| 学生 | 完成 S0–S5 全流程；触发提示、拒绝、小白解释、断线续答 |
| AI 助教 | 六阶段引导、三段式回复、提示升降级、拒绝与解释；**不写证明** |
| 教师 | 建班发码、审核题库、布置「必做」、查看看板与学生过程、导出、复测 |
| 系统（前端 + 后端） | 阶段机、预算计数、草稿保存、计时、埋点、异常兜底 |

### 1.2 白话名词

| 名词 | 白话解释 |
|---|---|
| 分步写证明 | 不要求一次写一大段，而是一步一个输入框：这一步写了什么 + 为什么能这么写（依据）。 |
| 依据 | 这一步引用的定义、定理、已知条件或上一步结论。相当于「法官判案要引哪条法」。 |
| 第一处可疑步骤 | AI 从学生当前提交的步骤里，只挑**最靠前**的一个有问题的地方提问，不逐条批改，也不判整题对错。 |
| 覆盖表 | 终稿核对时，把出题人预设的 5 个关键要点转成 5 个问句，逐条问学生「你写到了吗」；≥80%（5 条中 4 条）才算过。 |
| 量词 | 「任意/存在」「对每个/有一个」这类词；证明里最常错的地方就是它们的顺序和谁依赖谁。 |
| 提示预算 | 每道题允许用几次提示：L1 最多 3 次、L2 最多 3 次、L3 最多 2 次、L4 最多 1 次，合计 ≤9 次；L0 追问最多 6 次，不占预算。 |
| 阶段 | 六阶段 P1–P6：知识激活 → 拆题 → 分步推进 → 终稿核对 → 五问复盘 → 迁移总结。 |
| 独立完成 | 分三档：独立=全程只用 L0 追问；半独立=用过 L1–L2；依赖=用过 L3–L4 或出现粘贴标记。只用于教师端观察，不做惩罚、不合成单一百分比。 |

## 2. 8 步使用流程（逐屏展开）

> 编号沿用《契约》第 3 节：步 0–步 8。每一步都回答五个问题：学生看到什么、学生做什么、AI 做什么、系统做什么、产出与下一步。

### 步 0｜进班（S0 登录入班）

| 项目 | 内容 |
|---|---|
| 学生看到 | 产品名「证明陪练场」；一句话「这里不给答案，帮你把证明自己写出来」；输入框「邀请码」「学号」；主按钮「进入练习」；次按钮「先看看演示」；底部一行隐私说明。 |
| 学生做什么 | 输入教师给的 6 位邀请码 + 学号（30 秒内完成），点「进入练习」；或点「先看看演示」进入演示态（不写数据）。 |
| AI 做什么 | 无（不调用模型）。 |
| 系统做什么 | 校验邀请码/学号格式；记录入班时间、设备类型；演示态使用预置数据并标记 `demo_flag`。 |
| 产出 | 学生与班级绑定；S1 首页数据开始加载。 |
| 下一步条件 | 校验通过 → S1；失败 → 错误提示「邀请码或学号不对，请找老师确认」+ 重试。 |

### 步 1｜到达（S1 首页/今日任务）

| 项目 | 内容 |
|---|---|
| 学生看到 | 问候语；**本周必做 3 题进度**（如 2/3 已完成）；**继续上次**卡片（题名 + 上次到第几步）；**复测提醒**（如「11 月 28 日，还有 28 天」）；主按钮「开始选题」。 |
| 学生做什么 | 点「继续上次」恢复上次题目；或点「开始选题」进入 S2；或点复测提醒看说明。 |
| AI 做什么 | 无。 |
| 系统做什么 | 计算本周必做进度；读取最近一次未完成题目的 `resume_token`；距复测 <7 天时提醒高亮。 |
| 产出 | 学生进入 S2 或恢复 S3。 |
| 下一步条件 | 有未完成草稿 → 可继续；无 → 只能选题。 |
| 空状态 | 新学生：「这周还没有题，先从第一道开始吧」，直接给「开始选题」。 |

### 步 2｜选题（S2 选题）

| 项目 | 内容 |
|---|---|
| 学生看到 | 三组筛选：章节 / 知识点 / 难度；题目卡片列表：题干前 2 行 + 标签「必做/选练」+ 预计用时 + 「开始这道题」。 |
| 学生做什么 | 按筛选找题；点「开始这道题」（或从 S1 继续上次）。 |
| AI 做什么 | 无。 |
| 系统做什么 | 记录 `problem_id`、筛选条件、开始时间；同一题已有草稿则提示「你有上次的草稿，继续吗？」 |
| 产出 | 进入 S3，题目加载完成。 |
| 下一步条件 | 题目存在且已发布（教师审核过）→ S3；否则按钮置灰并显示「该题暂未开放」。 |

### 步 3｜读题（S3 的 P1 知识激活，≤2 轮）

| 项目 | 内容 |
|---|---|
| 学生看到 | 顶部阶段进度条（第 1/6 阶段 · 读题核对）、计时器；题面区（可折叠）；AI 对话区第一条消息：「这题要你证的是哪个结论？先别动手。」；输入框提示「用你自己的话说」。 |
| 学生做什么 | 用自己的话说「这题要证什么」；回答 1 个定义核对问题（如「什么叫条件收敛？」）。 |
| AI 做什么 | **只核对定义，不讲课**；正确则进 P2；不准确则追问或给定义原文（≤2 轮）；2 轮不过给小白解释或标记薄弱点，允许「带病前进」。 |
| 系统做什么 | 记录阶段、轮次、定义核对是否通过、薄弱点；P1 轮次 >2 时强制给「继续/休息」二选一。 |
| 产出 | 学生复述 1 条核心定义/定理条件，或带病前进标记。 |
| 下一步条件 | 正确复述 → P2；2 轮未过 → 定义原文/小白解释 → 仍不过 → 记录薄弱点 → 允许进入 P2。 |

> 白话：这一步不教知识，只确认学生脑子里「要证的东西」长什么样，避免后面白写。

### 步 4｜拆题（S3 的 P2 学生拆题，≤2 轮）

| 项目 | 内容 |
|---|---|
| 学生看到 | 阶段进度条变为第 2/6；AI 消息：「这题要证几件事？先攻哪件？」；草稿区出现「一句话题意」输入框。 |
| 学生做什么 | 说出目标 + 至少 1 个约束/关键词（如「要证两件事：收敛、条件收敛；关键词是交错级数」）。 |
| AI 做什么 | **只补漏、纠误解，不替学生解析**；不列「这题考什么、用什么方法」；通过后追问先攻哪一件。 |
| 系统做什么 | 记录拆题轮次、目标数、约束数；未达条件时提示「还差一个关键词」。 |
| 产出 | 一句话题意复述（存为阶段产出）。 |
| 下一步条件 | 说出目标 + ≥1 个约束 → P3；否则再追问 1 轮；2 轮未达 → 用「二选一」帮学生确认（仍由学生选）。 |

### 步 5｜分步写证明（S3 的 P3 分步推进，≤9 轮，核心循环）

| 项目 | 内容 |
|---|---|
| 学生看到 | 阶段进度条第 3/6；左侧/上方题面；中部**分步草稿区**：「第 N 步」输入框 + 「这一步的依据」输入框 + 「提交这一步」；下方 AI 对话区；右下悬浮「要一点提示（还剩 6 次）」；弱化文字入口「我卡住了，想直接看答案」；顶部「草稿已自动保存 12:31」。 |
| 学生做什么 | 写一步、写依据、提交；按 AI 反馈改这一步再提交；卡住点提示；想看答案点拒绝入口；阶段小结时回答检查问题。 |
| AI 做什么 | 每轮严格三段：【判断】引用学生原话给判断 →【提示】按等级给最小信息 →【提问】只 1 个问句；**只指第一个可疑步骤**；升提示需满足触发条件；L3/L4 后必须要求学生复述。 |
| 系统做什么 | 每轮记录阶段、提示等级、提示原文、诊断结论、学生输入、预算消耗；每 2–3 轮插阶段小结；单步 >8 分钟或连续 4 次失败触发 L4 建议/转教师建议；计时只在角落显示已用时间，不倒数、不弹焦虑提示（C3）；教师端保留完整计时数据。 |
| 产出 | 学生逐步写出的证明（每步含依据）。 |
| 下一步条件 | 证明写完且每步有依据 → P4；轮次到 9 仍未完成 → 三条出口（只做 L0 追问 / 转教师 / 换更小题）。 |

### 步 6｜交终稿（S4 终稿核对 + 五问复盘）

| 项目 | 内容 |
|---|---|
| 学生看到 | 阶段进度条第 4/6；学生终稿（只读，可回改）；**覆盖表**：5 个问句 + 每行「已覆盖/待补」；「确认提交终稿」按钮；覆盖 ≥80% 后出现 **五问复盘卡**。 |
| 学生做什么 | 通读终稿；逐条回答覆盖问句；点提交；填写五问复盘卡（5 个问句）。 |
| AI 做什么 | 内部核对关键要点，**清单必须问句化**；覆盖不足时用问句补缺项；不给参考证明、不代写复盘卡；学生 3–5 句复述主线。 |
| 系统做什么 | 计算覆盖度（命中要点数/总要点数）；≥80% 才解锁 P5；记录终稿文本、覆盖表结果、复盘卡内容、用时。 |
| 产出 | 终稿 + 覆盖表（≥80%）+ 五问复盘卡（5 问均有学生答案）。 |
| 下一步条件 | 覆盖 ≥80% 且 3–5 句复述通过 → P5；复盘 5 问均有学生自己的答案 → P6。 |

### 步 7｜迁移（S5 迁移总结，≤2 轮 + 变式题独立预算 ≤8 轮）

| 项目 | 内容 |
|---|---|
| 学生看到 | 阶段进度条第 6/6；「写下你带得走的 3–5 条规律」（带示例占位）；「自检卡」模板 6 行；「变式题」卡片（只给题面）；「看看我的掌握度」按钮。 |
| 学生做什么 | 自己写 3–5 条规律（每条 ≤20 字、可执行动作）+ 自检卡；做 1 道变式题并提交。 |
| AI 做什么 | 校正学生表述（不代写）；出变式题（只给题面，不给解法）；变式题只给对错 + 一条追问；给掌握度。 |
| 系统做什么 | 记录规律条数、自检卡内容、变式题结果、掌握度；变式题独立预算 ≤8 轮，不占主题预算。 |
| 产出 | 规律 + 自检卡 + 变式题结果 + 掌握度。 |
| 下一步条件 | 规律和自检卡完成 + 变式题提交 → 完成页；可跳过变式但记录跳过。 |

### 步 8｜结束（S5 完成页 + 一个月复测提醒）

| 项目 | 内容 |
|---|---|
| 学生看到 | 「你自己写完了这道题」；覆盖 5/5；掌握度（星级或百分比）；规律与自检卡（可复制/保存）；变式题结果；「一个月后回来复测」提醒卡片。 |
| 学生做什么 | 查看、复制规律/自检卡；可立即做变式题或离开。 |
| AI 做什么 | 无新内容；只展示学生自己产出 + 掌握度说明。 |
| 系统做什么 | 写完成标记；训练完成 → 进入复测提醒队列；若中途离开，草稿保留 24 小时（`resume_token`）。 |
| 产出 | 完成记录、掌握度、复测提醒。 |
| 下一步条件 | 无（可回到 S1 做下一题）。 |

## 3. 六阶段状态机（开发与测试口径）

### 3.1 阶段总表

| 阶段 | 进入条件 | 学生动作 | AI 动作 | 产出 | 退出条件 | 硬约束 | 对应页面 |
|---|---|---|---|---|---|---|---|
| **P1 知识激活** | 进入题目（S3 加载完成） | 用自己话说题意；回答 1 个定义核对问题；必要时复述小白解释 | 只核对定义/定理条件，不讲课；不通过给定义原文或小白解释 | 学生复述 1 条核心定义/定理条件；或「带病前进」标记 | 正确复述 1 条定义/定理条件，或记录薄弱点后带病前进 | ≤2 轮；只核对不讲课；小白解释 ≤2 次/题 | S3 |
| **P2 学生拆题** | P1 退出 | 说出目标 + 至少 1 个约束/关键词；说先攻哪件事 | 只补漏、纠误解；不列考点/方法 | 一句话题意复述 | 学生说出目标 + ≥1 个约束 | ≤2 轮；不列考点/方法 | S3 |
| **P3 分步推进** | P2 退出 | 写一步 + 写依据 → 提交 → 按反馈改写 | 诊断 → 只指第一处可疑 → 追问依据 → 不够才升提示 → 交还学生 | 学生逐步写出的证明（每步有依据） | 证明写完且每步有依据 | ≤9 轮；每轮只推进一个认知动作；L1–L4 预算 | S3 |
| **P4 终稿核对** | P3 退出 | 交终稿；逐条回答覆盖问句；3–5 句复述主线 | 内部对照关键要点，输出覆盖反馈 + 缺项追问；不给参考证明 | 覆盖表（要点问句 / 是否覆盖） | 覆盖 ≥80% 且复述通过 | 1 轮；清单必须问句化 | S4 |
| **P5 五问复盘** | P4 退出 | 用自己的证明回答五问复盘卡 | 核对、纠偏，不代写 | 五问答案（学生自己写） | 5 问均有学生自己的答案 | 1 轮；不代写、不复述参考证明 | S4 |
| **P6 迁移总结** | P5 退出 | 写 3–5 条规律 + 自检卡；做 1 道变式题 | 校正表述、出变式题（只给题面）、给掌握度 | 规律、自检卡、变式结果、掌握度 | 规律与自检卡完成 + 变式题提交 | ≤2 轮；变式题独立预算 ≤8 轮 | S5 |

### 3.2 轮次与时长预算分配

| 项 | 上限 | 说明 |
|---|---|---|
| 主流程总轮次 | ≤16 | P1 ≤2 + P2 ≤2 + P3 ≤9 + P4 1 + P5 1 + P6 ≤2，另允许 1 次拒绝轮 |
| 单题用时 | ≤25 分钟 | 学生端只显示已用时间（C3：不倒数、不弹焦虑提示）；教师端按 25 分钟统计超时；AI 回复末尾可轻提「要不要先保存」，不阻断 |
| L1 / L2 / L3 / L4 | 3 / 3 / 2 / 1 | 合计 ≤9，用尽后只能 L0 追问或转教师 |
| L0 追问 | ≤6 | 不占提示预算，但占轮次 |
| 小白解释 | ≤2 | 不占预算，用后必须回严格表述 + 复述 |
| 变式题 | ≤8 轮 | 独立预算，不占主题预算 |

### 3.3 状态机补充规则（来自 v1.0 第 3、5 节）

1. **阶段小结**：每 2–3 轮插一句「回顾 + 一个检查问题」，阶段切换时给「进度条」式人话反馈。
2. **铺垫只说类型**：结尾只说下一阶段做什么类型的事（「下一步处理绝对收敛」），不预告做法（不说「用比较判别法」）。
3. **不跳阶段**：学生要求跳过 → 做一道 2 分钟核对题，通过则标「免修」；不通过按原流程走。
4. **阶段回退**：P3 中若 P1/P2 暴露的知识错误反复出现，可回退补 1 轮定义核对（计入总轮次），不重开题目。
5. **拒绝轮**：学生要答案的拒绝轮不推进阶段，只计 `refusal_count`，不占提示预算，但占 16 轮总预算中的 1 轮。
6. **跨会话续答**：提示计数与阶段进度按 `problem_id` 累计，切设备/断网不清零（防刷）。

## 4. 异常分支处理（固定文案库）

> 统一原则：**先接住情绪 → 再说规则 → 立刻给一个 60 秒内能做的动作**。所有异常都只记录、不羞辱、不扣分。

| # | 异常 | 触发识别 | 系统/页面反应 | AI 固定处理 | 记录字段 | 兜底 |
|---|---|---|---|---|---|---|
| E1 | 学生要答案（点入口或文字） | 点「我卡住了，想直接看答案」；输入含「给我答案/完整证明/直接告诉我」 | 弹出 S3b 拒绝卡片（不用跳页） | 三段式：接住 → 一次说清规则 → 四选一替代动作（定义原文 / 二选一入口 / 只点评一步 / 转教师）；总长 ≤100 字；**连续两次拒绝必须换一种替代** | `refusal_count`、触发方式 | 第三次起转教师工单；永不输出证明 |
| E2 | 学生贴答案（粘贴 ≥80 字或速度异常） | 前端粘贴事件/输入速度 | 输入框下方轻提示「这段是你自己想的吗？」（不拦截） | 不指责；问「这段里哪一步是你自己没想到的？只写这一步，我只看它」；仍要求自己写终稿 | `paste_flag`、`paste_len` | 终稿仍走覆盖表；不因粘贴直接判零 |
| E3 | 学生说看不懂 | 输入含「看不懂/没学过/忘了/什么意思」；同一概念错 2 次 | 展示 S3c 小白解释卡（默认收起，点了才展开） | 三件套：一句日常类比 + 一个与本题无关的最小例子 + 回到严格定义/定理原文；要求复述；≤2 次/题 | `plain_explain_count`、概念名 | 照旧不懂 → 降到最小一步 / 转教师 |
| E4 | 学生放弃（输入「不做了/太难了/退出」或长时间无操作） | 关键词语义 + 5 分钟无输入 | 弹「要不要换个更小的题？」（保留当前草稿） | 降难度（同知识点更简单题）、语气转支持、建议休息、可转教师；不道德绑架 | `abandon_flag`、`exit_step` | 换题保留已用提示池（防刷） |
| E5 | 断网/切屏 | 网络监听失败；页面失焦 >30 秒 | 顶部黄条「网络不稳，草稿已保存在本机」；恢复后显示「草稿已恢复」 | 不因断网判失败、不重置提示计数；恢复后从原轮次继续 | `offline_cnt`、`focus_lost_cnt`、`recovered` | 草稿本地加密暂存，24 小时内可续 |
| E6 | 计时到（单题 25 分钟） | 后台时长到阈值 | **不弹焦虑提示**（C3）：角落已用时间保持灰字；仅在 AI 回复末尾附一句「做了一会儿了，要不要先存草稿下次继续？」；保存按钮常驻 | 不再升提示等级；只允许 L0 追问 | `time_on_task`、`saved_exit` | 保存退出后 24h 内可续，阶段与预算保留；教师端看到完整计时 |
| E7 | 提示预算用尽 | L1–L4 合计到 9（或某级到上限） | 提示按钮变灰，出现软着陆卡片：① 标记本题薄弱点（存数据）②「先看定义卡」（只给定义原文）③「换一道同知识点更简单题」④「转教师」；不再显示无限追问入口（C6） | 只做 L0 追问（0 新信息）或建议上述出口；不再连续追问 | `budget_exhausted`、`weak_point`、`soft_landing_action` | 严禁重新开题刷提示（同题跨会话累计） |
| E8 | AI 误判（学生指出「我这步是对的」） | 学生文字申诉 | 弹「可能是我看错了，先回到这一步」；该轮不计入失败次数 | 立即回退该轮、道歉、标记误判样本，再继续；同一题两次低置信转教师 | `misjudge_flag`、`rollback_turn` | 人工抽检复核；误判不进入学生画像负面 |
| E9 | 重复提交（连点/同内容再交） | 提交按钮 2 秒内重复点击；文本与上轮相似度 >0.95 | 按钮防抖；提示「这一步和刚才一样，是要改哪里吗？」 | 不重复给提示、不重复计数；把学生引回「哪一步变了」 | `dup_submit_cnt` | 连续 3 次重复 → 建议看提示或转教师 |
| E10 | 超时（单轮等待 >3 分钟） | 单步停留 >3 分钟 | 计时器变黄；不强制 | 若学生主动提交后仍无进展 → 触发 L2 建议（需学生点确认，不自动升） | `stall_min` | 单步 >8 分钟且失败 ≥4 次 → 建议 L4/转教师 |
| E11 | 情绪激烈（辱骂/「我太笨了」） | 情绪词典/分类器 | 轻提示「先喘口气，我们只看一步」 | 不评判；回到最小动作（「只把第 2 步发我」）；连续出现转教师 | `neg_sentiment`、`frustration_score` | `frustration_score ≥0.7` → L4 或转教师 |
| E12 | 多设备/并发登录 | 同一学号新会话 | 提示「你在另一台设备上也在做这道题」；以最新提交为准 | 提示计数跨端累加；会话合并到同一 `problem_id` | `device_cnt`、`session_merge` | 防刷提示：合并计数、不重复给预算 |
| E13 | 完全空着、说「不会写/不知道从哪下手」 | 输入为空或含「不会写/没思路/从哪开始」 | 不报错、不催；输入框下方出现「最小起步动作」引导卡（C2） | L0 允许「最小起步动作」话术：「先只写你要证的结论那一句，不用完整，写完我陪你看下一步。」仍属 L0，不升级、不占提示预算 | `empty_start_cnt`、`starter_hint_used` | 连续 3 次空提交 → 建议看定义卡/换更小题，不指责 |

> 情绪相关阈值（`frustration_score`）来自调研草稿 04-引导策略与Prompt模板.md 4.2.3，属内部口径，标注「待验证」，不作为学生可见内容。

## 7. 验收标准（Given / When / Then，共 17 条）

| # | Given（前提） | When（操作） | Then（可观察结果） | 验收方式 |

| AC4 | 学生在任意阶段 | 点「我卡住了，想直接看答案」或输入「给我完整证明」 | 返回三段式拒绝（≤100 字），含 ≥1 个替代动作；消息中不出现禁用收尾词、编号步骤或证明骨架；`refusal_count +1` | 文案抽检 + 正则 |
| AC5 | 学生在 P3 粘贴 ≥80 字他人答案 | 提交 | 系统记录 `paste_flag`；AI 只点评其中一步并追问「哪一步是你自己没想到的」；不给出整题对错 | 交互测试 + 日志 |
| AC6 | AI 已给 L3 或 L4 提示 | 学生不做复述直接提交下一步 | 下一轮先要求复述（「用你自己的话把这一步的理由说一遍」）；未复述不进入新步骤 | 对话脚本测试 |
| AC7 | 学生一轮提交 3 步且至少 2 步有错 | 提交 | AI 只指出**最靠前**的一处可疑，不提第二处；不判整题对错（D1 默认口径） | 金标准 120 条回归 |
| AC8 | 学生 P3 写到一半断网 | 断网 30 秒后恢复 | 顶部提示「草稿已保存在本机」→ 恢复后显示「草稿已恢复」，已填内容与提示计数不丢 | 弱网模拟 |
