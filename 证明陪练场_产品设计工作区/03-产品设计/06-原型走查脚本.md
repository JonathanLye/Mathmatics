## 0. 一页纸

- **目标**：用 10 分钟让罗老师/甲方相信三件事——① 学生真的自己写（不给答案）；② 卡住时提示是「够得着的最小一步」；③ 老师真的能看到过程数据。
- **演示题**：判断级数 ∑(−1)^(n−1)/√n 的收敛性；若收敛，是条件收敛还是绝对收敛？证明你的结论。
- **10 个可点击节点**：严格对应《契约》第 7 节节点 1–10。
- **一票否决**：演示过程中只要出现完整证明、最终答案、可抄的编号步骤，演示即失败（无论其他多好）。

## 1. 演示前 5 分钟准备清单

| # | 准备项 | 通过标准 |
|---|---|---|

| 5 | 计时器（手机倒计时 10:00） | 不超时 |

## 2. 10 分钟演示脚本

> 每一行：时间 → 点哪里 → 说什么 → 期望对方看到什么。**台词可以直接照读**。

| 时间 | 点击路径 | 你要说什么（台词） | 期望对方看到 / 感受 |
|---|---|---|---|
| 0:00–0:40 | 停在 S0，不动 | 「先看一句话：这个产品**不给答案**。学生每写一步，系统只问一句『你这一步的依据是什么』；卡住了，按五个等级一点点给提示，最多示范一行，剩下必须他自己写。老师那边看到的是过程数据，不是分数。」 | 第一分钟就把红线立住；对方点头或追问「真不给？」 |
| 0:40–1:20 | S0 点「先看看演示」→ S1 | 「学生用邀请码 + 学号 30 秒进班。首页只回答一个问题：今天做什么。这周必做 3 题、已完成 1 题；点『继续上次』回到上次的步骤。」 | 看到「不给答案」的预期从首屏开始；流程短 |
| 1:20–2:00 | S1 →「开始选题」→ S2，指章节/知识点/难度筛选，点一张「必做」题 | 「选题按章节、知识点、难度筛，必做是老师安排的。题目预览确认后再进去。」 | 看到题库 + 必做/选练标签，理解「老师审核后可见」 |
| 2:00–2:40 | S2 点「开始这道题」→ S3；节点 1：点「填入示例作答」=「要证收敛，还要判断条件/绝对」 | 「进来第一件事不是写，是核对定义。AI 问：条件收敛的定义是什么？」 | 看到**先核对定义、不讲课**；知道 P1 存在 |
| 2:40–3:20 | 节点 2：填入「要证两件事」 | 「学生自己拆题：要证两件事，先攻哪件。AI 只补漏，不替他解析。」 | 看到拆题是学生说的，不是 AI 讲的 |
| 3:20–4:40 | 节点 3：填入「u(n)=1/√n 递减，因为分母变大」→ 节点 4：填入「1/√(n+1)<1/√n」 | 「AI 只指出第一处可疑：『分母变大』还不是证明，要求写出 n 和 n+1 的不等式。学生写出来后，AI 追问：极限为 0 的依据呢？每一步必须有依据。」 | **关键一幕**：只标一处、追问依据、不代写 |
| 4:40–5:20 | 节点 5：点「要一点提示」→ 打开 S3a，选 L2 | 「卡住了可以点提示。看这个浮层：五级分别给多少、你还剩几次、为什么能升到下一级。现在给 L2：只给方向，不给式子。」 | 看到提示预算透明、逐级释放；**没有一键答案** |
| 5:20–5:50 | 节点 6：填入「因为 n^(1/2)→∞，所以 1/√n→0」 | 「L3 只给一步操作，给完立刻交还：『下一句你补。』」 | 看到「给一步就收手」的分寸 |
| 5:50–6:30 | 节点 7：点「我卡住了，想直接看答案」→ S3b | 「现在看红线。学生要答案时：先接住情绪，再说清为什么不能给，最后给一个 60 秒能做的替代动作，四选一。」 | **最重要一幕**：拒绝不是冷冰冰的「不行」，而是有替代 |
| 6:30–7:00 | 节点 8：点「看不懂」→ S3c 小白解释卡 | 「学生说看不懂概念时，只给三样：一句生活类比、一个跟本题无关的最小例子、然后回到严格定义，并要求他复述。讲完立刻回到题目。」 | 看到「讲懂」与「替做」的边界 |
| 7:00–7:40 | 节点 9：点「交终稿」→ S4 覆盖表 | 「终稿不是 AI 批改。系统把出题人预设的 5 个要点变成 5 个问句，让学生自己核对。覆盖 ≥80% 才能进复盘。」 | 看到覆盖表是**问句**不是标准答案；看到没有「参考证明」按钮 |
| 7:40–8:20 | 节点 10：填五问复盘卡 → S5 | 「最后学生自己写 3–5 条规律、一张自检卡，再做一道变式题。这些东西是学生带得走的。」 | 看到完成页奖励的是「学生产出」，不是分数排行榜 |
| 8:20–9:30 | 切 S6 教师端：指标卡 → 卡点 Top5 → 未完成名单 → 点学生开详情抽屉 → 指「导出」按钮 | 「老师这边：完成率、未完成名单、平均提示轮数、卡点知识点 Top5、独立完成率。点学生能看到他每一步、每次提示、哪里卡住。导出默认匿名，姓名学号不出现。」 | 看到过程数据闭环；罗老师能对应到自己班级 |
| 9:30–10:00 | 切 S7 流程总览，收尾 | 「全流程就这一张图：学生 8 步、六阶段、老师闭环。今天想请罗老师拍板三个问题：① 单步能不能说『对了』；② 提示次数是按 3 次还是不限；③ 试点 4 周还是 16 周。其余细节我们可以按今天的意见改。」 | 对方带着 3 个明确决策离开，而不是一堆疑问 |

### 2.1 演示失败 / 被追问的预案

| 情况 | 应对 |
|---|---|
| 原型报错/卡住 | 「这版是快速原型，个别交互还不稳。我们看这段预置录屏，效果一样。」10 秒内切换备用录屏 |
| 对方说「这不就是聊天机器人？」 | 指 S3b 拒绝模板 + S3a 提示预算：「普通聊天机器人不会拒绝你、也不会记录你用了第几级提示。我们的差别在约束和过程数据。」 |
| 对方说「学生还是能去别处找答案」 | 「对，我们防不住他开另一个 App；但我们能防住『在我们这里直接抄到』，并且用变式题 + 复述关卡让他没法只抄不做。」 |
| 对方说「老师哪有时间审 50 题」 | 给 05 文档第 8.3 节时间预算：4 周约 10.5 小时，可拆成每周 20 分钟；也可教研预审 + 教师 3 分钟终审。 |
| 对方说「AI 讲错了怎么办」 | 「首版 AI 只定位第一处可疑并提问、不判整题；低置信时只复述追问；每 10% 对话人工抽检，误判可回退并标记样本。」 |
| 对方问「能不能直接给我看它怎么证明这道题」 | 「这正是我们不做的。如果您想看参考证明，它只存在于教师端题库里，不在学生端。」（如原型未做教师端参考证明，说明「本轮原型不展示，正式版只在教师端」） |

## 3. 原型验收清单（12 个必须出现的元素；已并入《契约》4.1 补充规则 C1–C6）

> 验收方式：对照原型逐项勾选。**「一票否决」项任一命中，整体不通过。**

### 3.1 一票否决（3 条，任一命中即失败）

| # | 否决项 | 判定 |
|---|---|---|
| V1 | 原型任意页面出现完整证明、最终答案、可抄的编号步骤/表格/证明骨架 | 出现即失败 |
| V2 | 「要答案」入口点了之后没有任何拒绝或替代动作，直接给解答 | 出现即失败 |
| V3 | 教师端只有分数、没有过程数据（卡点/提示次数/是否独立完成） | 出现即失败 |

### 3.2 必须出现的 12 个元素

| # | 元素 | 应出现的位置 | 通过标准 |
|---|---|---|---|
| 1 | 邀请码 + 学号 + 演示模式入口 + 隐私说明一句话 | S0 | 四样齐全，30 秒能进 S1 |
| 2 | 本周必做 3 题进度 + 继续上次 + 复测提醒 + 进入选题 | S1 | 四样齐全，进度可见 |
| 3 | 章节筛选 + 知识点 + 难度 + 必做/选练标签 + 题面预览 | S2 | 筛选可点、标签可见、预览可展开 |
| 4 | 阶段进度条 + 角落已用时间（C3：不倒数不施压）+ 题面区 + 分步草稿（步骤 + 依据）+ AI 对话区 + 提示按钮（含剩余预算）+「我要答案」入口 + 草稿已保存提示 | S3 | 九项齐全；已用时间在角落且不倒数；提示按钮显示剩余次数；草稿保存提示可见 |
| 5 | L0–L4 说明 + 当前可用级别 + 剩余次数 + 升一级的理由 | S3a 浮层 | 五级说明齐全；当前级别高亮；升级理由可见 |
| 6 | 拒绝三段式 + 60 秒替代动作（四选一） | S3b 浮层 | 接住 → 规则 → 替代动作三块齐全，四个替代按钮可见 |
| 7 | 一句类比 + 与本题无关的最小例子 + 回到严格表述 | S3c 小白解释卡 | 三件套齐全，且与「本题做法」无关 |
| 8 | 要点覆盖表（问句化）+ 五问复盘卡 + 提交 | S4 | 5 行覆盖表全部是问句；五问可填；提交入口可见 |
| 9 | 覆盖 5/5 + 掌握度 + 3–5 条规律 + 自检卡 + 变式题 + 复测提醒 | S5 | 六样齐全；规律/自检卡为学生可编辑产出 |
| 10 | 完成率 + 未完成名单 + 平均提示轮数（带解释文案，区分同题/跨题，C4）+ 独立完成三档（分列，C1）+ 卡点知识点 Top5 + 学生详情抽屉 + 题库审核状态 + 导出按钮 | S6 | 八项齐全；三档分列不合成百分比；抽屉能打开；导出按钮可见 |
| 11 | 角色动线 + 页面流转图 + 六阶段状态图 + 红线说明 | S7 | 四块齐全，一屏能看完 |
| 12 | 每屏一个「设计意图」标注 + 全局红线可见（提示预算/拒绝模板/无参考证明） | 全局 | 每屏都能找到设计意图；任意页面找不到「参考证明/标准答案」入口 |

### 3.3 加分项（不强制；其中 C2/C6 已于 2026-10-31 升级为契约 P0）

- 手机窄屏（375px）下 S3 不发生横向滚动、输入框不被键盘遮挡；
- 断网提示与「草稿已恢复」demo；
- S3 的「提示预算用尽」软着陆（按钮变灰 → 定义卡 / 换同知识点简单题 / 转教师，C6）；
- 完全空着时出现「最小起步动作」话术（C2，仍 L0 不升级）；
- 覆盖 <80% 时「交终稿」置灰并说明还差几个要点。

> 2026-10-31 更新：C2（最小起步动作）与 C6（预算用尽软着陆）已被 Lead 采纳为契约 §4.1 的 **P0** 项，原型 v1.2 已实现，不再按「加分项」验收；C4（平均提示轮数解释）同为 P0 文案项。
