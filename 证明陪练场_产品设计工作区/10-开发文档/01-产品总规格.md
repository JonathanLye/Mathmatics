# 01 · 产品总规格

> 口径：以 `../08-重构原型/index.html` 的交互与规则为基线，`../07-重构审计与方案/02-全新融合方案.md` 为规格依据，本文件在此基础上落实本轮新增需求（2026-11-02 与老师对接后）。冲突时以本文件为准，并在 `00-README.md` 决策日志里留痕。

## 0. 一页纸

- **是什么**：数学分析证明写作陪练。学生在手机上一行一行写证明（手写为主），系统只提问、只给教师预写的分级提示，绝不替学生写；教师看到完整的过程数据。
- **本轮新增**：
  1. 手写为主（全屏手写 → 识别 → 学生确认），证明键盘为辅，拍照上传默认开启。
  2. "问一句 / 要提示 / 批注"合并为**一个求助入口、三种意图**，数据上严格区分（§4）。
  3. 第 1–2 层改为**记忆核验 + 分步可视化讲解**：学生不会时在应用里学会，不必跳出去问别的 AI（§3、§7）。
  4. 第 4 层自检改为"导入时由 AI 出题、教师审核，运行时按学生自己的行号挑题"；第 5 层迁移题是完整题目包。
  5. 练习/测验双模式的诚信策略（§6，详见 11）。
  6. 教师端全过程监控、实时看板、镜像预览与回放（§8，详见 04）。
  7. 题库从华东师大版同步辅导 PDF 导入（详见 10）。
- **AI 生成边界**（已确认）：第 1–2 层是公共知识，AI 可以现场判断学生的自然语言描述、生成补充讲解与图解参数；第 3 层与迁移题，学生看到的提示与批注只来自教师审核过的预写文本；模型在第 3 层只做归类与路由，不产生学生可见的数学内容。
- **红线的可执行定义**（沿用 v3）：系统发给学生的任何字符串，都必须经过闸门；**预写文本要求 100% 不含**学生尚未写出、也未计入透露量的关键步骤中可以直接照写的片段；**生成文本必须过闸门并上线前抽检，不承诺 0 泄题**。关键步骤由教师在题目包里登记。

## 1. 用户与场景

| 画像 | 先备 | 卡点 | 系统默认 |
|---|---|---|---|
| 新手（主体，大一） | 刚学定义，量词结构写不出来 | 不知道从哪写起；把极限理解为"越来越近" | 第 1、2 层完整走，微课自动弹出 |
| 过渡者 | 能写骨架 | 找 N、放缩、选判别法 | 第 1 层可跳；第 3 层提示阶梯起主要作用 |
| 高先备（考研） | 熟练 | 严谨性 | 第 1、2 层可跳；第 5 层迁移题为主 |

使用场景：晚上宿舍，手机或平板，单次 15–30 分钟，网络可能不稳；少数在电脑上。**手机是第一优先**，平板第二（触控笔手写体验最好），电脑第三。

## 2. 学生的一次完整使用

```text
收到老师的链接/二维码 → 输入班级邀请码 + 学号（30 秒）
  → 首次：知情同意页（服务所需 / 香港服务器存储 / 过程监测 为必选；境外决策模型 / 教研使用 为可选，不同意不影响功能）
  → 首页：进行中 / 待完成 / 已完成 / 本周"我自己写出的关键步骤"
  → 做题：六层（可跳的层有"已掌握，跳过"）
       L1 记忆核验 → L2 证明骨架 → L3 构造与推导 → L4 自检 → L5 迁移题 → L6 总结
  → 完成页：本题我自己写出了几个关键步骤、用了多少提示；mathlib4 对照（只列定理名）
  → 我的证明本：自己的证明 + 总结 + 通过核验后才展示的标准定义
  → 题目关闭后：老师发布的参考证明与讲评
```

任何时候可以"先搁置本题"，回来时从断点继续（服务端状态 + 本地草稿）。

## 3. 六层逐层规格

每层统一描述：学生做什么 / 系统可做 / 系统禁止 / 完成判据 / 跳过规则 / AI 边界。

### L1 记忆核验（原"前置知识点 / 定义核验"）

| 项 | 规格 |
|---|---|
| 目的 | 核验学生是否真的记得、理解本题要用的定义。不记得就在这里学会。 |
| 学生做 | 写出定义。**可以用自己的话**（"不管带子多窄，从某一项起都在带子里"），也可以用量词。输入方式：手写（默认）/ 键盘 / 拍照。 |
| 系统判定 | 题目包把定义拆成成分（如 ∀ε>0、∃N、n>N、\|aₙ−A\|<ε）和必要的先后顺序。判定 = 规则（canon 后正则）∪ 语义（Jev 逐成分 noul，且 DeepSeek 交叉同意，阈值见 09 §4.3）。 |
| 反馈 | 只指出**缺了哪一个成分**或"顺序会改变含义，你的顺序是哪个在前？"，一次只说一件事（批注锚在这一行下）。 |
| 不会时 | 点"看不懂"或**连续两次未通过** → 自动展开**分步微课**（§3.1）。 |
| 系统禁止 | 提及本题会用到的定理、方法或对象；微课和图解里**永不出现本题的数列/函数**。 |
| 完成判据 | 所有成分齐全且顺序正确。 |
| 跳过 | 学生自选"已掌握，跳过"（P0）；P1 起可配置为"本学期同一定义已核验通过 2 次才可跳"。跳过会记录。 |
| AI 边界 | 可实时：判定自然语言描述、按学生的具体误解生成 ≤150 字补充讲解（过闸门 + 异厂商复核，失败回退预写微课）。 |

#### 3.1 分步微课（第 1、2 层共用）

微课内容来自**概念库**（`concept.schema.json`，导入时 AI 起草、教师审核），不属于任何一道题：

1. **直观**：一句话直观说法 + 交互图解（如 ε 带：拖动 ε，看从第几项起点都落进带子里）。
2. **对应**：直观词 ↔ 符号的对照表。
3. **失真说明**：这个直观说法会让人误解什么（必须带反例，如"常数列也有极限，没有'越来越近'"）。
4. **边界例子**：一道"几乎满足但不满足"的选择题。
5. **回到定义**：回到原题，重新写定义。

每一步都有一道小核验题，答对才能进下一步，答错给一句引导后可重试。可以随时关掉回到题目。微课的进入、每步、每次核验、图解交互都记事件。

**按学生原话补充（P0 有开关，默认开）**：学生两次未通过时，服务端把学生原话 + 缺失成分交给 DeepSeek 生成一段针对性的补充（如"你写的'越来越接近 A'少了'对任意给定的误差'这层意思……"），经闸门 + Qwen 复核后放在微课第一步上方。生成失败、超时、复核不过 → 不显示，只用预写微课。

### L2 证明骨架（原"题目解析"）

| 项 | 规格 |
|---|---|
| 学生做 | 写出证明的形式框架：开头写什么、结尾落到什么、中间要构造的是什么（如"任取 ε>0 … 取 N=（待构造）… 当 n>N 时 … <ε"），再加一句"真正要解决的是什么"。 |
| 系统可做 | 骨架属于形式部分，可以强反馈；"看通用骨架"按钮给出通用模板（不计透露量）；骨架微课（概念库 `frame-*`）。 |
| 系统禁止 | 给出中间要构造的内容（N 的表达式、该用哪个判别法）。 |
| 完成判据 | 题目包登记的骨架检查项全部具备。 |
| 跳过 | 同 L1。 |
| AI 边界 | 同 L1（可实时判定、可生成补充，过闸门）。 |

### L3 构造与推导（核心）

| 项 | 规格 |
|---|---|
| 学生做 | 一次写一行："这一行"（结论）+ "依据"（为什么成立）。顺序不限。手写/键盘/拍照；识别结果必须学生确认后才提交。 |
| 系统判定 | 引擎把这一行归类到题目包的关键步骤（允许多条路线）或常见错误。**P0：规则为准，Jev 影子**；P1 起按评测结果让 Jev 在高置信时生效（09 §4）。 |
| 批注（系统主动） | 一行一条，锚在该行下方，**只用问句**，不说"对/错"。例：命中错误 → 该错误的追问；命中关键步骤且有依据 → "第 3 行和前面衔接上了。"；没写依据 → "依据没写。它由哪条定义或已证结论得到？"；归不了类 → "第 3 行和要证的结论是什么关系？它的依据是哪条定义或定理？"；低置信 → 只给 H0 式追问，并标记给教师抽检。 |
| H4 示范行 | 提示示范过的那一步，学生必须在"依据"里用自己的话写出它为什么成立（≥6 字），才算学生自己写出的关键步骤。 |
| 卡住 | 两次提交都没有新关键步骤 **且** 超过 3 分钟 → 求助按钮上出现温和的"要一条提示吗？"（不自动给）。 |
| 完成判据 | 学生点"写完了"，且某条路线的关键步骤全部出现在学生自己的文本中。没闭合时只说"还有一处需要的结论没有出现。回到骨架看看：链条哪里断了？"（P0 只校"齐全"；顺序与依赖校验用 `KeyStep.deps`，列 P1；P0 完成页标注"未校验逻辑顺序"。） |
| 系统禁止 | 任务说明、批注、"下一步"预告里出现任何关键步骤内容；说"这一步对了"。 |
| AI 边界 | 模型只输出结构化归类（`{choice, conf}`），学生可见文本 100% 来自题目包预写。 |

### L4 自检（原"完整讲解"）

| 项 | 规格 |
|---|---|
| 学生做 | 针对**自己写的证明**回答 3 个局部问题。 |
| 题目来源 | 导入时 AI 生成 6–8 道候选题（按维度：依据 / 作用 / 逻辑地位 / 去掉条件 / 模块 / 迁移），教师审核后进题目包 `selfcheckBank`。运行时引擎挑 3 道（一题"依据"、一题"作用"、一题"逻辑地位或条件"），把模板里的 `{line:K2}` 替换成**学生自己写出 K2 的那一行的行号**。 |
| 判定 | 规则：引用的行号必须存在且在被问的行之前；`mentions` 型检查关键词；`jev` 型由 Jev 判断（P0 影子，规则兜底：≥4 字即接受）。不合格时只追问一句，不给答案。 |
| 系统禁止 | 提供"标准讲解"。页面不出现任何讲解文本。 |
| 跳过 | 可跳（教师可按班关闭本层）。依据：自我解释对证明理解有效（Hodds 2014），但在例题学习中叠加反而可能负向（Barbieri 2023），所以只问 3 题、可跳、效果列为待检验。 |

### L5 迁移题（原"同类题"）

- 一道独立的完整题目包（`kind: transfer`），走 L3 流程，透露预算默认 1（主题的一半）。
- 从主题的完成页进入；创建子作答（`parentAttemptId`）。
- 可跳；若主题已用满预算，界面改为"推荐下一题"而不是强推迁移题。

### L6 总结

- 五问，每问一句话：这个证明证了什么？分几块、块与块什么关系？哪个选择决定了成败？写到哪一步才算证完？哪个做法下次还能用、哪个只适用于本题？
- 与题目包"要点卡"比对（规则 + Jev），**只对缺失的要点追问一句**（如"你的总结没有提到 N 和 ε 的依赖关系。它重要吗？"），追问一次后无论是否补上都算完成。
- 完成后：总结进入"我的证明本"；显示 mathlib4 对照（只列定理名与步骤名，步骤名只对学生自己写出的步骤显示）。

### 题目关闭后：教师讲评

由教师决定是否发布参考证明与基于学生作品的讲评（A、B 组同时发布）。发布前学生调用 `/review` 返回 403。

自学题（学习路径、练习区）没有教师发布这一步：学生自己做完后即可看讲评（只含标记为可发布的参考证明）。班里这道题还有没结束的测验时，一律不给，避免早交卷的人把答案带给还在考的同学。

### 学习路径与练习区

- **学习路径**：首页按课程 → 章 → 单元排成一条路径。点节点开始一道题，服务端按班级懒创建自学布置（`origin='path'`），引擎与作答流程与老师布置的题完全相同；班里有开放的教师练习布置时直接复用它。班里这题有没结束的测验时拒绝从路径开始（409 `TEST_IN_PROGRESS`）。
- **软锁**：同一单元里排在第一道未完成题之后的节点、以及上一单元完成不到 60% 的单元显示“未解锁”，确认后可以跳过去，不硬拦；单元完成 60% 就开放下一单元，避免一道有问题的导入题卡死整条路径。
- **练习区**：学生在全部已发布题里按章节、难度（入门 / 进阶 / 挑战，对应题目包难度 1–2 / 3 / 4–5）自选，也可随机一道没做完的。列出的题一定完整、可证明（有 secret 与至少一份参考证明），下架、迁移题、测试卷与备用题不出现。
- **解题思路**（`secret.walkthrough`：思路、关键点、易错点）与参考证明只在学生**主动查看**或**做完**后出现；主动查看只对自己的练习模式自学作答开放，老师布置的题和测验永远不开放。查看记 `solution.revealed` 事件；查看之后写出的关键步骤按“有提示”计，看过完整解答后不再给关键步骤经验和“无提示通关”。
- 导入的题只启用写证明（L3）与总结（L6）两层；种子题保留全部六层。

## 4. 求助体系：一个入口，三种意图

用户反馈"问一句"和"要一条提示"看起来是一回事。本轮合并为**一个"求助"按钮**（手机上在底部操作坞右侧，拇指区），打开底部抽屉：

```text
┌──────────────────────────────────────┐
│ 你现在需要哪种帮助？                     │
│  [ 我卡住了，不知道下一步 ]   → 提示阶梯    │
│  [ 这个概念/符号我不懂 ]      → 概念解释    │
│  [ 帮我看看这一行 ]          → 行检查（批注）│
│ ─────────────────────────────────────│
│ 或者直接问一句：[____________] [发送]      │
│ 常见问题：这一行在做什么？ 什么是充分条件？   │
└──────────────────────────────────────┘
```

| | 批注 | 求助·卡住了（提示） | 求助·不懂这个（概念） | 求助·看这一行（行检查） |
|---|---|---|---|---|
| 谁发起 | 系统，学生每次提交后 | 学生 | 学生 | 学生 |
| 内容 | 锚在该行下方的一个问句 | 当前关键步骤的 H0–H4 预写提示 | 术语词条（1–2 句）；第 1–2 层可打开微课 | 对指定行（缺省最新一行）给一条批注 |
| 是否计透露量 | 否 | H0/H1 否；H2 0.5；H3/H4 1（按步骤取最高级，全题求和 ≤ 2） | 否 | 否 |
| 门槛 | — | 从 H2 起：自上一条提示后又提交过一行；同级停留 20 秒；30 秒内连点 3 次锁 60 秒 | 第 3 层只给定义级内容 | 每行限 2 次 |
| 显示位置 | 行内 | 右栏/抽屉里，署名"H2 · 透露 0.5" | 抽屉里，署名"助教" | 行内 |

规则要点：

1. **花之前告知代价**：H2 起，先返回预览卡"下一条是方向提示，会计入透露 0.5（你已用 0.5 / 2）。领取 / 先不要"，学生点"领取"才下发。预览和领取都记事件。
2. **自由提问**：服务端先用规则（关键词）再用 Jev 判意图，路由到上面三类之一；判不出时按"概念"处理，答不了就说"这个我不展开，只回答本题涉及的数学概念和你写的这一行"。
3. **索要答案 / 施压**（"直接给答案""老师说可以""求你了"……）：一句话拒绝（不说教）+ 当前可做的 H0。理由永远不变，不因任何说法改变计数。记 `pressure` 事件。
4. **额度用完**：不再升级提示；给出软着陆选项——回到第 1 层看定义 / 打开微课 / 先做下一题再回来 / 标记求助老师 / **申请一次 H4（教师授权）**。教师授权后该步必须先用自己的话写出依据（≥6 字）才计入；本题标记"含教师补发"，不计入独立完成统计。
5. **测验模式**：求助按钮整体隐藏（教师可配置只保留"概念"）。

## 5. 输入：手写为主，键盘为辅，拍照可选

详细规格见 `03-手写键盘与识别.md`。产品层面的规则：

- 默认输入方式是**手写**；键盘与拍照在同一个输入条里一键切换，系统记住学生上次的选择。
- 手写一次写一行（证明行、依据、定义各自独立），写完点"识别"。识别结果以公式渲染形式展示，**学生确认（可修改）后才提交**；两路识别不一致的地方高亮请学生核对。
- 识别永远是"抄写员"，不是"批改员"：识别提示词要求逐字转写，**不得纠正学生的错误**（研究发现视觉大模型会"顺手改对"学生的错，这对我们是致命的，也是泄题路径）。
- 拍照：拍一页草稿纸 → 切成若干行 → 学生逐行确认 → 依次加入。拍照来源在数据里单独标记，教师端显示 📷 徽标。
- 键盘：自研证明键盘（量词、关系、模板、证明句式），屏蔽系统键盘避免遮挡；"中"键切回系统键盘写中文。

## 6. 练习模式与测验模式

| | 练习（默认） | 测验（教师设定时段） |
|---|---|---|

## 7. 留存设计：为什么学生不会跳出去问豆包

学生跳出去，通常是因为三种时刻：①看不懂定义；②卡住了不知道往哪走；③写完了不知道对不对。本产品对应的设计：

| 时刻 | 本产品在应用内给什么 | 衡量 |
|---|---|---|
| 看不懂定义 | 第 1 层分步微课 + 交互图解 + 针对原话的补充；术语随点随答 | 微课完成率；微课后 L1 通过率 |
| 卡住 | 一个入口的求助，提示分级、先告知代价；卡住 3 分钟温和询问；额度用完有出路（回定义 / 先做下一题 / 求助老师） | 首次求助前尝试时长；额度用完后的放弃率 |
| 不知道对不对 | 每行一条问句批注；"帮我看看这一行"；完成判据明确（链条闭合）；完成页显示"我自己写出的关键步骤" | 写完了的点击次数；完成率 |
| 低成本回来 | 30 秒登录；断点续做；草稿离线保存；首页"进行中"置顶 | D1 / D7 回访；搁置后回来的比例 |
| 有收获感 | 我的证明本（自己的证明 + 总结 + 通过核验后展示标准定义）；本周"自己写出的关键步骤"；老师讲评引用（匿名）学生作品 | 证明本打开率 |

**游戏化（00 U14 取代原“不做”）**：做经验、连胜、每日目标、徽章，吉祥物全程陪伴，音效与动效可关闭。**仍不做**扣命（没有“生命值”惩罚）和公开排行榜（不做班级/年级排名展示）。奖励只按**学生自己写出的关键步骤**发放；提示不给分，也不因用提示扣分，避免鼓励抄答案、点提示刷分。测验模式不显示游戏化元素。语气保持平实，庆祝语温暖但不夸张，也不替代追问。

## 8. 教师闭环（概要，详见 04）

## 10. 文案与语气

- 一次只问一个问题；问句优先。允许温暖的庆祝语（如完成一层、守住连胜），但庆祝只针对“你写出了关键步骤 / 你完成了”，不夸张、不泛泛夸人（U14）。
- 证明行上不说“对/错”（庆祝语也不例外），说"衔接上了 / 依据我没看到 / 和要证的结论是什么关系？"。
- 拒绝只说一句，紧接着给一个能做的动作。
- 所有 AI 生成文本下方小字："AI 生成 · 仅作学习提示"。
- 数学一律用 KaTeX 渲染；不在中文句子里夹 LaTeX 源码。
