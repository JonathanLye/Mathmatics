# 12 · 分工与开发计划

> 目标：**Day 3（建议 2026-11-05）晚上，一个班的学生在手机上真实练习**。下面的计划按 2 人编排，第 3 人到位时接手教师端。所有人都用 AI 写代码，所以本文写得足够具体，可以直接作为给 AI 的任务说明。

## 1. 三端与负责人

| 端 | 代码位置 | 技术 | 2 人方案 | 3 人方案 |
|---|---|---|---|---|
| 学生端 | `apps/student` | uni-app（Vue 3 + Vite + TS）+ TDesign UniApp，当前编译 H5 | **A** | **A** |
| 公共前端组件 | `packages/ui-math` | MathText 渲染、证明键盘、手写画布、识别确认、图解组件 | **A** | **A** |
| 服务端 | `apps/server` | Node 22 + TS + Fastify + Drizzle + PostgreSQL 16 | **B** | **B** |
| 策略核心 | `packages/engine` | 纯 TS 函数：canon、归类、预算、闸门、层状态机、回放 reducer | **B** | **B** |
| 后台任务 | `apps/worker` | pg-boss：识别排队、导入流水线、导出、Lean 编译、指标刷新 | **B** | **B**（导入归 C） |
| 教师端 | `apps/teacher` | Vue 3 + TDesign Vue Next + ECharts | **B** | **C** |
| 教师端接口 | `apps/server/src/routes/teacher`、`src/services/teacher`（`/teacher/*`） | 同服务端 | **B** | **C**（B 审；解锁、导出仍随 B 的诚信与导出任务） |
| 契约 | `packages/contracts`（即本目录 `contracts/`） | OpenAPI / JSON Schema / SQL | **B 维护，A 审** | B 维护，A、C 审 |

**接口边界**：前端与服务端之间只通过 `openapi.yaml` 和 `events.schema.json` 交流。前端永远不实现层、预算、门槛、归类的逻辑，只渲染服务端返回的 `state`。服务端永远不假设前端做过任何校验。

**为什么 B 同时管教师端**：教师端是数据最密的页面，字段几乎和服务端的查询一一对应，同一个人写最省沟通；它也是 P0 里最能简化的一端（表格 + 轮询即可）。3 人方案下同理：教师端页面与 `/teacher/*` 接口都归 C，B 负责认证、引擎、作答与事件，并审 C 的服务端代码。

## 2. 仓库骨架（Day 0 第一小时，B 建，A 拉）

```text
proof-gym/
├─ apps/
│  ├─ student/            uni-app 工程（src/pages、src/components、src/mocks）
│  ├─ teacher/            Vite + Vue 3 + TDesign Vue Next
│  ├─ server/             Fastify：src/routes、src/services、src/db（drizzle）、src/ai、src/gate
│  └─ worker/             pg-boss 任务：recog、import、export、lean、metrics、partitions
├─ packages/
│  ├─ contracts/          ← 复制本目录 contracts/；生成 ts 类型：openapi-typescript、json-schema-to-typescript（复制后以 10-开发文档/contracts 为唯一源，禁止双源手改）
│  ├─ engine/             纯函数 + vitest；不依赖数据库和网络
│  └─ ui-math/            Vue 3 组件，学生端与教师端镜像/详情页共用
├─ infra/                 docker-compose.yml、Caddyfile、backup.sh、.env.example
├─ docs/                  软链接到本目录（10-开发文档）
├─ AGENTS.md              给 AI 的总规则（见 §8）
└─ pnpm-workspace.yaml
```

命令约定：`pnpm dev`（三端并起，前端默认连 Prism mock）、`pnpm test`、`pnpm check:contracts`、`pnpm e2e`。

**B**

## 5. 各模块完成标准（DoD）

- **任何接口**：在 `openapi.yaml` 里；响应通过 schema 校验；错误码在表里；有一条契约测试。
- **任何会改变作答状态的接口**：写事件、同一事务、`state_version` +1；回放 reducer 能从事件重建出同样的 state。
- **任何外发给学生的文本**：经过 `gate()`；有单测覆盖"本该拦截的被拦截"。
- **任何前端页面**：390 / 768 / 1280 三档截图；深色模式；加载、空、错误、离线四种状态都有。
- **任何模型调用**：写 `app.model_calls`；有超时；有降级；能用开关关掉。
