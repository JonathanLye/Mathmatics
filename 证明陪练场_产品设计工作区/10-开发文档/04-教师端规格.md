# 04 · 教师端规格

> 适用：`apps/teacher`（Vue 3 + TDesign Vue Next；图表自绘 HTML/CSS，已移除 ECharts）。桌面优先；实时看板与学生详情在手机上可只读查看（需求书"手机可看"）。
> 设计语言与学生端同一套 token（02 §2），信息密度更高：表格行高 40px，正文 14px。

## 1. 信息架构

```text
登录
└─ 我的班级（卡片：班名、学期、人数/已认领、进行中的布置）
   └─ 班级
      ├─ 实时看板（默认页）
      ├─ 布置（列表 / 新建练习 / 新建测验 / 发布讲评）
      ├─ 名单（导入 CSV、邀请码、认领状态、实验分组）
      ├─ 指标（按布置汇总、趋势）
      └─ 导出
   学生作答详情（从看板或名单进入；抽屉或独立页）
   └─ 镜像预览 / 回放（P1）
题库
├─ 题目列表（状态：草稿 / 待审核 / 退回 / 已发布 / 下线）
├─ 导入（P1：选 PDF 页码范围 → 任务进度 → 草稿列表）
└─ 审核（P1：三栏审核屏）
设置（账号、TOTP、默认诚信策略、默认预算）
```

权限：教师只看自己的班级；管理员看全部并审批实名导出；助教角色（P1）只读看板与详情。

## 2. 实时看板

### 2.1 布局（≥ 1280px）

```text

│ 在线 23  已开始 41/58  已完成 12  卡住 6  求助 2  诚信提醒 3              │ ← 数字卡，点击即筛选下表
├───────────────────────────────┬─────────────────────────────────────┤
│ 层漏斗                          │ 关键步骤卡点                            │
│ L1 ███████████ 41              │ K1 化简 |aₙ−3|     已写出 30 · 卡住 2 · 经提示 4 │
│ L2 █████████ 35                │ K2 放大            已写出 18 · 卡住 9 · 经提示 7 │ ← 红色程度 = 卡住人数
│ L3 ██████ 28                   │ K3 取 N            已写出 13 · 卡住 3 · 经提示 2 │
│ …                              │ K4 串成链          已写出 12 · 卡住 1 · 经提示 0 │
├───────────────────────────────┴─────────────────────────────────────┤

│ S-7K2Q9M（张三）          L3   1/4       0.5   6 分钟   2 次   求助     10 秒前   │ ← 默认按"无进展时长"降序
```

- 姓名只在教师端显示（名单导入时提供才有）；导出默认不含。
- 行状态色：活跃（灰）、空闲 > 1 分钟（浅灰）、离开中（琥珀点）、卡住（红笔左边线）、已完成（绿）、锁定（深灰 + 锁）。
- 点行 → 右侧抽屉打开学生详情（§4）；抽屉里有"镜像预览"（P1）。

### 2.2 刷新

P0：每 5 秒轮询 `GET /teacher/classes/{id}/live`；页面不可见时暂停。P1：SSE `GET /teacher/classes/{id}/stream`，事件 `row` / `flag` / `ping`，断线用 `Last-Event-ID` 续传。

### 2.3 状态定义

| 状态 | 判定（服务端计算） |
|---|---|
| 未开始 | 没有作答 |
| 活跃 | 最近 60 秒内有事件 |
| 空闲 | 60 秒 – 5 分钟没有事件，且页面可见 |
| 离开中 | 最近一条 `integ.visibility` 是 `hidden` |
| 卡住 | 第 3 层：连续 2 次提交没有新关键步骤，且距上一个新关键步骤 ≥ 3 分钟（同学生端主动询问的条件） |
| 搁置 / 锁定 / 已完成 | 作答状态 |

### 2.4 视觉改版 v2（2026-11-06，现行）

- 视觉语言与学生端一致（见 02 §0）：TDesign 主题深度定制（`--td-brand-color:#127AB0`、粗描边、硬下沿），Nunito + 系统中文粗体；深/浅色可切换。
- **看板**：顶部 KPI 筛选卡（需要你 / 卡住 / 在写 / 离开中 / 已完成 / 未开始），点击筛选并显示"筛选：xx / 清除"；学生卡片（状态色条、6 段层进度、关键步骤 pip、透露灯泡）与表格视图可切换；默认按"需要你"程度排序；右侧"需要你"队列 + "全班在哪一层"。
- 状态判定与排序为纯函数 `src/utils/liveBoard.ts`（单测覆盖）：优先级 完成 > 空闲 > 求助（锁定/求助/额度用尽）> 卡住（无进展 ≥180s）> 离开 > 在写。该判定只改展示，不改 §2.3 的服务端状态口径。
- **指标页**：层漏斗、关键步骤卡点改为自绘条形（`src/charts/LayerSteps.vue`、`KeyHeatBars.vue`），n<10 规则不变；ECharts 依赖已移除。
- **学生详情抽屉**：头像 + 状态、吸顶干预栏、来源图标（手写/键盘/拍照）、提示等级徽标、时间线语义色圆点。
- **班级列表**：课程卡（色块头 + 吉祥物 + 已认领进度环 + 邀请码）。

## 3. 指标（看板与"指标"页）

口径以 `08-事件与数据字典.md` §4 为准，这里只列教师看到的名字与一句话解释（页面上每个数字旁有 ⓘ 显示同样的解释）。样本 < 10 人时只显示人数，不显示百分比。

| 指标 | 一句话 |
|---|---|
| 完成率 | 见 08 §4.2：已完成作答数 / 已开始作答数（另给 / 名单人数） |
| 独立度 | 1 − 透露量 / 关键步骤数（0–1）；跨题不可比（不同题 keysTotal/预算不同），只用于同题比较；显示中位数与四分位（定义见 08 §4.1） |
| 独立度分档 | ≥0.85 独立 / 0.5–0.85 有提示 / <0.5 依赖（阈值可配置；定义见 08 §4.1） |
| 自主覆盖率 | 见 08 §4.1：匹配到的关键步骤中从未领取 H2 及以上提示的比例 |
| 首次求助前时长 | 进入第 3 层到第一次领取 H2 及以上提示的时长（中位数） |
| 提示后停留 | 领取提示到下一次提交的时长（中位数）；太短说明没读 |
| 连点 | 触发连点锁的次数 |
| 层漏斗 | 到达/完成每一层的人数；跳过单独标出 |
| 关键步骤卡点 | 每个关键步骤：自己写出、经提示写出、卡在这里的人数 |
| 识别修改率 | 识别结果被学生改过的比例；高说明识别差或书写难 |
| 离开 | 每人离开次数与总时长（中位数） |

## 4. 学生作答详情

```text
S-7K2Q9M（张三） · epsN v1 · 练习 · 第 3 层 · 已用时 18 分（前台 15 分）      [镜像预览] [发一句话] [解锁]
┌ 证明（学生写的） ───────────────────────────────┐ ┌ 时间线 ─────────────────────────┐
│ L1 定义  ✍  "∀ε>0 ∃N …" 第 2 次通过（rule+jev）     │ │ 20:01 开始                        │
│ L2 骨架  ⌨  "任取 ε>0 …" 通过；看过通用骨架           │ │ 20:03 L1 未通过（缺顺序）           │
│ L3                                               │ │ 20:04 打开微课 seq-limit，5/5 步     │
│ 1 ✍ |aₙ−3|=5/(n+2)    依据：通分   K1 ✓ 规则        │ │ 20:09 L1 通过                      │
│    识别：5/(n+2)（未改）                           │ │ 20:12 L3 第 1 行 K1                 │
│ 2 ✍ 5/(n+2)<5/n       依据：—     K2 ✓ 规则 Jev0.88 │ │ 20:15 求助·卡住了 → H2（透露 0.5）    │
│    批注：依据没写……                                │ │ 20:16 离开 30 秒                     │
│ 3 📷 N=n+1            依据：…     E1 N 依赖 n       │ │ 20:18 第 2 行 K2                    │
│    批注：你取的 N 里出现了 n……                       │ │ …                                 │
├ 提示 ─────────────────────────────────────────┤ ├ 诚信 ─────────────────────────────┤
│ K2 · H2 · 透露 0.5 · 20:15 · 停留 41 秒            │ │ 离开 2 次，共 52 秒                 │
├ 求助 ─────────────────────────────────────────┤ │ 第 3 行来自拍照                     │
│ 20:20 自由提问"N 取多少" → 施压 → 拒绝 + H0           │ └──────────────────────────────────┘
└──────────────────────────────────────────────┘
```

- 每行显示：来源徽标（✍ 手写 / ⌨ 键盘 / 📷 拍照 / 📋 粘贴）、归类结果与来源（规则 / Jev / 低置信）、对应批注、识别原文与是否改过；手写行有"回放笔迹"按钮（P1）。
- 教师能看到关键步骤名和归类（学生看不到）。
- 低置信归类显示"待抽检"，教师可一键改判（写 `audit_log`，不改变学生已看到的内容）。

## 5. 镜像预览与回放（P1）

### 5.1 镜像预览

- 教师端点"镜像预览" → `POST /teacher/attempts/{id}/mirror-token` 取 5 分钟令牌 → iframe 打开学生 H5 的 `/s/mirror?attempt=…&token=…`。
- 镜像模式：学生端同一套页面，只读（所有输入与按钮禁用，顶部标"老师预览中 · 只读"仅教师可见），数据来自教师权限的状态接口，并订阅该作答的 SSE（每次 `state_version` 变化推送）。教师看到的就是学生此刻的页面（当前层、已写的行、展开的批注）。
- P2：实时笔迹（学生书写时每秒推送一次增量笔画）。
- 打开/关闭写 `t.mirror` 事件；同意书里已告知"老师可以查看你的作答过程"。

### 5.2 回放

- 时间轴滑块 + 播放速度（1× / 4× / 16×）；拖到任意时刻，用 `packages/engine` 的 `replay(events, uptoSeq)` 重建当时的 `AttemptState`，复用镜像页面渲染。
- 时间轴上标出：层切换、提交、提示、批注、离开（琥珀段）、识别。
- **回放能否完全重建页面，就是"数据是否记全"的检验**：e2e 测试对每个作答比较 `replay(全部事件)` 与 `attempts.state`。

## 6. 干预

| 操作 | 说明 |
|---|---|
| 解锁 | 测验模式切出过多被锁时；可同时补发一条 H4（额度耗尽出口，记 `teacherOverride`）；写 `attempt.unlock` 与 `audit_log` |
| 发一句话 | ≤ 200 字，过闸门（规则 + Jev）；含学生尚未写出的步骤时不发送并告知教师。学生端以"老师"署名显示在页边 |
| 处理求助标记 | 标记已处理，可附备注（"课上讲"） |
| 处理诚信信号 | 忽略 / 已记录 / 已面谈；只是记录，系统不自动处罚 |
| 关闭布置 / 发布讲评 | 布置关闭后可发布参考证明（从题目包 `referenceProofs` 里选）与一段讲评；A/B 组同时发布 |

## 7. 布置练习 / 测验

| 字段 | 练习默认 | 测验默认 |
|---|---|---|
| 题目 | 只能选已发布版本 | 同左 |
| 开放 / 截止 | 必填 / 可空 | 必填 / 必填 |
| 启用的层 | 题目包配置 | 只 L3（可改） |
| 透露预算 | 2 | — |
| 求助 | 开 | 关（可只开"概念"） |
| 拍照 | 开 | 关 |
| 切出处理 | 记录 + 轻提醒 | 3 次锁定 |
| 限时 | — | 可设（分钟） |

已开始的作答固定在开题时的题目版本上，修改布置不影响它们。

## 8. 题库与审核（P1）

### 8.1 列表

题号、标题、章节、来源（书 · 章 · 例/习题号）、类型（主题/迁移）、版本、状态、自动校验（✓/✗ 四项）、最近审核人、是否“AI 整理”（`reviewSource='auto'`）。

题库上千题时列表按（题号, 版本）分页（`GET /teacher/problems?limit=&cursor=`），布置练习时的选题下拉用 `q` 做远程搜索；不传 `limit` 的旧调用照旧返回全部。

### 8.3 自学进度（学习路径）

学生在首页学习路径或练习区自己开始的题，服务端按班级懒创建“自学布置”（`origin='path'`）。它们**不进**实时看板、指标、布置列表和导出，也不会抢走看板默认选中的布置；教师只在单独的“自学进度”视图里看：`GET /teacher/classes/{id}/self-study` 返回每位学生在各单元完成了几道、有几道进行中、几道主动看过解答。

### 8.2 审核屏（三栏）

```text
┌ 原书页面 ────────────┬ 题目包（可编辑） ───────────────────┬ 自动校验与分歧 ─────────────┐
│ p.30 页图             │ 题面  [MathText 编辑 + 预览]           │ ✓ schema                      │
│ （可放大；高亮条目）    │ 定义成分 ×4  [规则][缺失批注][Jev 说明] │ ✓ KaTeX                       │
│ OCR 文本（只读）       │ 骨架检查 ×4                            │ ✗ 穷举泄题：K3.H1 含"N≥5/ε"   │ ← 点击跳到对应字段
│                      │ 关键步骤 K1…Kn（多路线）                │ ✓ 规则自测（样例全命中）        │
│                      │   规则 · 样例 · leak · H0–H4 · 透露量   │ 分歧 3 处（A/B 两稿 + 仲裁理由）  │
│                      │ 常见错误 · 自检题库 · 要点卡 · 迁移题    │ Lean：未编译 [编译]            │
│                      │ 参考证明（只用于讲评与审核）            │                              │
├──────────────────────┴───────────────────────────────────┴─────────────────────────────┤
│ [以学生视角预览：L1 / L3 写了 K1 / 额度用完 / L6]      用时 42 分钟   [退回] [修改后通过] [通过]  │
└───────────────────────────────────────────────────────────────────────────────────────┘
```

- "通过"要求四项自动校验全绿；否则按钮置灰并提示先修。
- "以学生视角预览"用引擎模拟几个典型状态，看学生会看到哪些文字。
- 记录审核用时（研究与工时估算用）。

## 9. 导出

- 表：作答汇总、证明行（长表）、提示、求助、识别、诚信、事件（JSONL）。字段见 08 §5。
- 格式：CSV（UTF-8 BOM）、Excel、JSONL。
- 默认匿名（只含匿名码）；实名导出需管理员审批，写 `audit_log`。
- 每个导出附一份字段字典（Excel 的第二个工作表 / CSV 同名 `.dictionary.csv`）。

## 10. 名单与班级

- 名单 CSV：`学号,姓名`（姓名可空），UTF-8 或 GBK 自动识别；重复学号合并；不合法行列出行号与原因。
- 学号只存密文与哈希；教师端显示姓名需要名单里有。
- 邀请码 6 位（去掉 0/O/1/I），可重置；重置后旧码立即失效，已登录学生不受影响。
- 认领状态：名单里每一行是否已有学生登录认领；可解除认领（学生换手机号/换设备异常时）。
- 实验分组（P2）：按班内个体随机分配 AB/BA 顺序，分配结果只对管理员可见。
