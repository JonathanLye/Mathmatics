# 13 · 合规与运营

> 本文是工程侧的合规清单，不是法律意见。标"待确认"的条目需要学校信息化部门或法务确认后才能定稿。

## 1. 处理了哪些个人信息

| 数据 | 是否个人信息 | 处理方式 |
|---|---|---|
| 学号、姓名（名单导入） | 是 | 加密存储；登录匹配用 HMAC；对外只用匿名码 |
| 学生登录密码 | 间接（账号凭据） | 只存 argon2id 哈希，不可逆；不进日志、导出、教师端 DTO；教师端只显示「是否已设密码」，忘记时由老师重置（清空哈希），不能查看或找回 |
| 设备 ID、IP（IPv4 /24、IPv6 /48 掩码） | 是 | 设备 ID 用于诚信信号；IP 只留 90 天 |
| 作答内容（证明行、笔迹、照片、求助原文） | 与学号关联时是 | 研究导出默认匿名；`app.help_requests` 只能经 anon_id/匿名导出读取，教师端按 04/13 的可见范围展示，禁止直接 join `app.users` 暴露学号 |
| 过程数据（事件、离开次数等） | 与学号关联时是 | 同上 |
| 年龄段 | 是 | 只存分档（< 14 / 14–17 / ≥ 18），用于未成年人规则 |

不收集：手机号、身份证号、精确位置、通讯录、摄像头视频（拍照只拍草稿纸，前端去 EXIF）。

## 2. 知情同意（P0 必须上线）

服务器已在中国境内（U22）。首次登录后、开始练习前必须签署；同意书有版本号，改文案必须升版本并让学生重新确认。

| 段（`items` 键） | 必选 | 白话要点 |
|---|---|---|
| 服务所需（`service`） | 是 | 处理学号、姓名、年龄段、作答内容（含笔迹和照片）、过程记录和登录设备信息；数据存储在中国境内 |
| AI 模型和识别服务（`crossBorderHosting`，历史键名） | 是 | 求助内容、定义和证明行去掉身份信息后发给 DeepSeek 或通义千问，手写笔迹和照片发给 SimpleTex 或通义千问；都在境内 |
| 过程监测（`monitoring`） | 是 | 见 11 号文档 §8 |
| 教研使用（`research`） | 否 | 匿名化后用于教学研究与论文；不同意不影响使用 |

`crossBorderModel`（境外决策模型 Jev）从 v2 起不展示，服务端不管客户端传什么都记为 `false`，模型网关因此跳过境外 provider（`ai/gateway.ts` 未同意即 `no_consent`）。契约里保留这个键，客户端仍要传。

完整的处理规则在公开页面《隐私政策》（`apps/student/src/copy/privacy.ts`，登录前可看，登录页、同意页、我的 → 隐私都有入口），写齐个人信息保护法第 17 条和网络数据安全管理条例第 21 条要求的事项。改数据流、保存期限或第三方时要同步改这个文件和 07 §7。

技术要求：同意记录写 `app.consents`（版本、各项选择、时间、IP 掩码、UA 哈希）；撤回入口在"我的 → 隐私"；撤回"教研使用"后，该生数据从研究导出中排除。**实现（Task 9）**：撤回 = 重新提交同意书且 `research=false`（`POST /consents`）；导出（`services/teacher/exports.ts`、`export/attempts-csv.ts`）只纳入「没有撤回过教研同意」的学生——曾同意 `research`、而最近一次有效同意里不再同意（含整份同意书被撤销）的学生，其作答、行、提示、求助、识别、诚信与事件都不再出现；重新同意后恢复。从未勾选过 `research` 的学生沿用既有导出口径（不在此排除）。重做作答（`kind=redo`）永远不进导出。

> 为什么模型服务设为必选：个人信息保护法第 16 条规定，不得以个人不同意为由拒绝提供产品或服务，除非该处理是提供服务所必需的。本产品的提问、批注和手写识别都依赖这些服务，所以按必需处理。**待学校确认**；若认定不是必需，要改成可选，并让不同意的学生走规则判定、预写内容和键盘输入。

## 4. 未成年人

- 名单导入时可带年龄段；未提供时登录后让学生自选（≥ 18 / 14–17 / < 14）。
- **< 14 岁**：不开通（需监护人同意的流程本期不做）。
- **14–17 岁**：可使用；同意书附加一句"建议告知监护人"；不做任何商业推广；数据最小化同成年人。
- 大一新生可能有 17 岁的，这一档必须支持。

## 6. 题库版权

题库来自已出版的教辅（《数学分析习题详解（华东师大第三版配套）》等），受著作权保护。

- 题面引用原题；提示、批注、自检题和解题思路由本项目和 AI 编写；参考证明由 AI 整理，学生主动查看或做完后可见。
- 只在本课程邀请制范围内使用；不对外公开、不整本分发；PDF 和 OCR 全文不进仓库，学生端不可访问。
- 题目卡片显示出处（`sourceBook`）；《隐私政策》写明权利人可联系下架；教师可在题库下架单题。

**这是目前最大的法律风险。** 著作权法第 24 条第（六）项只允许“为学校课堂教学或者科学研究，翻译、改编、汇编、播放或者少量复制已经发表的作品，供教学或者科研人员使用，但不得出版发行”，并要指明作者和作品名称、不影响作品正常使用。把 500 多道题放进线上系统给学生用，很难说是“少量”和“供教学或者科研人员使用”。需要学校确认，或向出版社取得授权；在此之前不要扩大到本课程以外，也不要商用。

## 7. 伦理审查

把过程数据用于研究、尤其是做 A/B 对照实验，依《科技伦理审查办法（试行）》属于"以人为测试、调查、观察等研究活动的对象"，需提交本校科技伦理（审查）委员会。

- Day 3 的上线定位为**教学练习试点**；数据照常完整记录。
- 研究使用（导出用于论文、开启 A/B 分组）在取得伦理批件后开始；`app.experiments.ethics_ref` 记录批件号，未填时系统不允许开启分组。

## 8. 网站备案与访问

服务器在境内（U22），未经备案不得从事互联网信息服务（非经营性互联网信息服务备案管理办法）。

- **ICP 备案**：备案号要标在主页底部中央，并链接工信部备案系统（`https://beian.miit.gov.cn/`），否则可被责令改正并罚款。学生端用 `SiteRecord` 组件显示（登录页、首页、关于页、政策页），值在 `apps/student/src/copy/privacy.ts` 的 `SITE`；教师登录页的值在 `apps/teacher/src/site.ts`，两处保持一致。
- **公安联网备案**：网站开通后 30 日内办理，备案号同样显示。
- 备案主体要和《隐私政策》写的运营方一致；如果学校是实际运营方，要走学校的备案。

### 10.2 日常

- 每天：看 `/health/details`（内网，需令牌）、昨日花费、错误率、识别 P95；处理教师反馈。
- 每周：备份恢复抽检；指标周报（完成率、独立度分布、识别修改率、诚信提醒）给罗老师。
- 每月：恢复演练；密钥检查；预建事件分区（自动）。

### 10.3 学生支持

- 班级群里一位同学做"小助手"收集问题；页面"我的 → 反馈"一键提交（附匿名码、设备、最近 20 条前端错误）。
- 常见问题：打不开（换浏览器打开）；识别不准（一次写一行、横屏写、改用键盘）；被锁（联系老师）；忘了学号格式（名单里的学号）。
