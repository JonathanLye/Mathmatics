# 13 · 合规与运营

> 本文是工程侧的合规清单，不是法律意见。标"待确认"的条目需要学校信息化部门或法务确认后才能定稿。

## 1. 处理了哪些个人信息

| 数据 | 是否个人信息 | 处理方式 |
|---|---|---|
| 学号、姓名（名单导入） | 是 | 加密存储；登录匹配用 HMAC；对外只用匿名码 |
| 设备 ID、IP（IPv4 /24、IPv6 /48 掩码） | 是 | 设备 ID 用于诚信信号；IP 只留 90 天 |
| 作答内容（证明行、笔迹、照片、求助原文） | 与学号关联时是 | 研究导出默认匿名；`app.help_requests` 只能经 anon_id/匿名导出读取，教师端按 04/13 的可见范围展示，禁止直接 join `app.users` 暴露学号 |
| 过程数据（事件、离开次数等） | 与学号关联时是 | 同上 |
| 年龄段 | 是 | 只存分档（< 14 / 14–17 / ≥ 18），用于未成年人规则 |

不收集：手机号、身份证号、精确位置、通讯录、摄像头视频（拍照只拍草稿纸，前端去 EXIF）。

## 2. 知情同意（P0 必须上线）

首次登录后、开始练习前必须签署；同意书有版本号，改文案必须升版本并让学生重新确认。

| 段（`items` 键） | 必选 | 白话要点 |
|---|---|---|
| 服务所需（`service`） | 是 | 为提供练习功能，需要处理你的学号、作答内容和过程记录 |
| 服务器位于中国香港（`crossBorderHosting`） | 是（P0 服务器在香港，不同意则无法使用 P0 版本） | 你的数据存储在中国香港的服务器上；国内模型（DeepSeek、通义千问）与识别服务（SimpleTex）在境内 |
| 境外决策模型（`crossBorderModel`） | **否** | 去掉身份信息后的作答文本会发送给境外的 Jev 决策模型，用于判断你写的是哪一步。P0 中它只做对比记录，不同意**不影响任何功能** |
| 过程监测（`monitoring`） | 是 | 见 11 号文档 §8 |
| 教研使用（`research`） | 否 | 匿名化后用于教学研究与论文；不同意不影响使用 |

技术要求：同意记录写 `app.consents`（版本、各项选择、时间、IP 掩码、UA 哈希）；模型网关在每次调用 Jev 前检查 `crossBorderModel`，未同意即跳过；撤回入口在"我的 → 隐私"；撤回"教研使用"后，该生数据从研究导出中排除。**实现（Task 9）**：撤回 = 重新提交同意书且 `research=false`（`POST /consents`）；导出（`services/teacher/exports.ts`、`export/attempts-csv.ts`）只纳入「没有撤回过教研同意」的学生——曾同意 `research`、而最近一次有效同意里不再同意（含整份同意书被撤销）的学生，其作答、行、提示、求助、识别、诚信与事件都不再出现；重新同意后恢复。从未勾选过 `research` 的学生沿用既有导出口径（不在此排除）。重做作答（`kind=redo`）永远不进导出。

> 为什么 Jev 是可选项：个人信息保护法第 16 条规定，不得以个人不同意处理其个人信息为由拒绝提供产品或服务，除非该处理是提供服务所必需的。P0 中 Jev 只跑影子，不是必需的；香港服务器存储则是 P0 提供服务所必需的。

## 3. 数据出境（已确认采用 Jev 云服务与香港服务器）

| 项 | 做法 | 状态 |
|---|---|---|
| 单独同意 | 同意书分别单列"香港服务器存储"（必选）与"境外决策模型"（可选）两段（个人信息保护法第 39 条要求告知境外接收方、目的、方式、种类，并取得单独同意） | P0 |
| 去标识化 | 发给 Jev 的只有数学文本与题目描述，不含学号、姓名、匿名码；作答 ID 哈希 | P0 |
| 出境规模与程序 | 依《促进和规范数据跨境流动规定》（2024），非关键信息基础设施运营者当年累计向境外提供不满 10 万人个人信息（不含敏感个人信息）的，可免于安全评估、标准合同与认证 | 待确认（本项目规模远低于此线，但需学校确认适用） |
| 个人信息保护影响评估 | 出境前做一次书面评估（目的、必要性、风险、措施），存档 | P0 前补齐，待确认格式 |
| 退路 | P2 迁回境内：服务器迁境内机房 + ICP；Jev 换为自部署的 Jev 同类开源模型（接口相同） | P2 |

## 4. 未成年人

- 名单导入时可带年龄段；未提供时登录后让学生自选（≥ 18 / 14–17 / < 14）。
- **< 14 岁**：不开通（需监护人同意的流程本期不做）。
- **14–17 岁**：可使用；同意书附加一句"建议告知监护人"；不做任何商业推广；数据最小化同成年人。
- 大一新生可能有 17 岁的，这一档必须支持。

## 5. 生成式 AI 相关

| 项 | 做法 | 状态 |
|---|---|---|
| 使用已备案模型 | DeepSeek、通义千问为已备案模型；Jev 是判别式决策模型、不生成内容 | P0 |
| 本应用是否需要备案 | 校内邀请制、面向本校学生使用，是否属于"向境内公众提供服务"需要确认 | **待确认** |
| AIGC 标识 | 显式：每条 AI 生成文本下方"AI 生成 · 仅作学习提示"；隐式：响应头 `X-AIGC: 1`、数据库记录 `source`、导出文件首行注释（依《人工智能生成合成内容标识办法》） | P0 |
| 内容安全 | 学生可见文本大部分为教师审核的预写内容；生成内容只在第 1–2 层且过闸门与复核 | P0 |

## 6. 题库版权

题库源《数学分析同步辅导及习题全解》（华东师大版配套教辅）为受著作权保护的出版物。

- 导入后的题目包中，题面引用原题，提示、批注、自检题、要点卡为本项目编写；参考证明仅教师可见，题目关闭后是否向学生发布由教师决定。
- 仅限本课程班级内部教学使用；不对外公开、不整本复制分发；页面图片与 OCR 全文只存在服务器，学生端不可访问。
- 是否属于著作权法规定的课堂教学合理使用范围、是否需要出版社授权：**待学校确认**。

## 7. 伦理审查

把过程数据用于研究、尤其是做 A/B 对照实验，依《科技伦理审查办法（试行）》属于"以人为测试、调查、观察等研究活动的对象"，需提交本校科技伦理（审查）委员会。

- Day 3 的上线定位为**教学练习试点**；数据照常完整记录。
- 研究使用（导出用于论文、开启 A/B 分组）在取得伦理批件后开始；`app.experiments.ethics_ref` 记录批件号，未填时系统不允许开启分组。

## 8. 网站备案与访问

- P0 香港服务器无需 ICP 备案，但**未备案域名在微信内置浏览器里可能被提示风险或拦截**。准备：①"在浏览器中打开"图示；②备用短链；③班级群公告说明。
- P2 迁境内：ICP 备案（约 2–4 周）→ 上线后 30 日内公安联网备案 → 小程序业务域名配置。

## 9. 安全事件响应

| 级别 | 例子 | 动作 |
|---|---|---|
| 一级 | 个人信息泄露、数据库被访问 | 立即下线相关接口；保留日志；24 小时内书面报告学校；按法规评估是否需通知学生与主管部门 |
| 二级 | 题目包保密内容泄露（提示原文外泄） | 下线该题；查 `reference_access_log` 与接口日志；换新版本 |
| 三级 | 服务不可用 | 按降级表处理（09 §11）；班级群通知 |

## 10. 运营

### 10.1 成本（试点规模：1–2 个班，60–120 人）

| 项 | 月费用 | 说明 |

### 10.2 日常

- 每天：看 `/health/details`（内网，需令牌）、昨日花费、错误率、识别 P95；处理教师反馈。
- 每周：备份恢复抽检；指标周报（完成率、独立度分布、识别修改率、诚信提醒）给罗老师。
- 每月：恢复演练；密钥检查；预建事件分区（自动）。

### 10.3 学生支持

- 班级群里一位同学做"小助手"收集问题；页面"我的 → 反馈"一键提交（附匿名码、设备、最近 20 条前端错误）。
- 常见问题：打不开（微信拦截 → 用浏览器打开）；识别不准（一次写一行、横屏写、改用键盘）；被锁（联系老师）；忘了学号格式（名单里的学号）。
