## 3. 给罗老师/甲方的问题（与调研文档联动）

完整访谈提纲与可直接转发的微信稿见 [../02-调研/03-罗老师访谈提纲与待确认问题.md](../02-调研/03-罗老师访谈提纲与待确认问题.md)。

最需要先回答的 7 个（按对开发的影响排序）：

1. **学生实际在什么场景用**：课后作业卡住？考前复习？课堂上？各自占比大概多少？
2. **现在学生卡住时怎么办**：问同学/搜题/问 AI/等老师答疑？老师最希望产品替代哪一段？
3. **AI 能不能说「这一步对/错」**：只标可疑，还是可以明确判单步？
4. **提示给到什么程度算「不给答案」**：L3 给一步具体操作、L4 示范 1–2 行，老师能接受吗？
5. **题库范围与来源**：先做哪些章节/知识点？50 题从哪来（真题/教材/自编）？谁审？
6. **课堂怎么组织**：老师布置还是学生自选？一周几题？要不要课上演示？
7. **数据与实验**：教师看板最想看的 3 个指标？前后测怎么排？匿名 ID 怎么发？

## 4. 待验证的假设（不要当结论）

| 假设 | 风险 | 怎么验证 |
|---|---|---|
| 学生愿意分步写而不是直接搜答案 | 高 | 3–5 名学生走查 + 课堂试用 |
| 手机输入证明可接受 | 中高 | 测单题输入时长；必要时做数分键盘/拍照转写 |
| 老师愿意每周花 1.5 小时审题 | 中 | 访谈确认档期 |
| 提示阶梯能既防泄题又不让学生挫败 | 高 | 160 条回归 + 学生测试 |
| 一个月后复测能组织起来 | 中 | 与罗老师排校历 |
