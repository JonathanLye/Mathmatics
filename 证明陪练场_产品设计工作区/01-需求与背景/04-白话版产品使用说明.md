# 白话版：这个产品学生到底怎么用

> 写给非数学背景的产品/评审/甲方看。读完你应该能不看原型，用 3 分钟讲清楚「学生打开后会发生什么」。
> 本文不追求数学严谨，追求**把流程讲明白**；严谨口径见《学生端使用流程 PRD》。

## 1. 先说清楚：数学分析证明题难在哪

数学分析（俗称「数分」）是数学系大一的核心课。它的作业不是算数，而是**证明**：给你一个命题，你要用定义、定理一步步推出结论。

学生最常见的状态不是「完全不会」，而是：

- 看老师的解答：「哦，懂了。」
- 合上解答，自己写：「……第一步写什么？」

这就像看别人游泳觉得简单，自己下水就呛水。**所以产品卖的不是「答案」，是「陪练」。**

## 2. 一句话讲产品

> 学生在手机上分步写证明，AI 像驾校教练一样坐在旁边：**不替你开，只在你快压线时点你一句**；写完后老师能看到你卡在哪、被提示了几次。

## 3. 学生完整用一遍：8 个动作

| 步 | 学生看到什么 | 学生要做什么 | AI 会做什么 |
|---|---|---|---|
| 1 进班 | 输入邀请码 + 学号 | 30 秒登录 | 无 |
| 2 首页 | 「本周必做 3 题」「继续上次」 | 点「开始」 | 无 |
| 3 选题 | 章节、知识点、难度筛选 | 选一道题 | 无 |
| 4 读题 | 题目 + 一个核对问题：「这题要你证什么？」 | 用自己的话说一遍 | 只核对定义，**不讲课**；说错就再问，最多 2 轮 |
| 5 拆题 | 「要证几件事？关键词是什么？」 | 自己拆 | 只补漏，不替你分析 |
| 6 写证明（核心） | 左边题目、右边 AI；中间「写一步 + 写依据」 | 写一步 → 提交 → 看反馈 → 改 | 只指出**第一个**可疑点，然后提问；你卡住才逐级给提示 |
| 7 交终稿 | 一张「要点覆盖表」+ 五问复盘卡 | 核对、回答五问 | 只问「你有没有写到××」，**不给参考证明** |
| 8 总结 | 掌握度、3–5 条规律、自检卡、一道变式题 | 自己写规律、做变式 | 校正表述、出题、给建议 |

**一个月后**：学生收到复测提醒，做一套同知识点、同难度的平行题，用来对比进步。

## 4. 一个具体的故事（约 25 分钟）

小林是大一学生，晚上 9 点在宿舍用手机做本周第 2 题：

> **题目**：判断级数 1 − 1/√2 + 1/√3 − … 是收敛还是发散；如果收敛，是条件收敛还是绝对收敛？

1. 她先写：「要证收敛，还要判断是条件收敛还是绝对收敛。」AI 问：「条件收敛的定义是什么？」她答：「收敛，但绝对值级数发散。」——这一步她其实会，AI 只是确认。
2. 她写：「u_n=1/√n 递减，因为分母越来越大。」AI 没给答案，只问：「能用 n 和 n+1 写一个不等式吗？」她补上 1/√(n+1) < 1/√n。
3. 她卡在「极限为什么是 0」。点了「提示」，系统先只提醒「你学过 1/n^α 的极限」，还不够，再升一级给方向；最后示范一行，并要求她用自己的话复述。
4. 她想直接要完整证明。AI 拒绝：「给了你整份证明，明天考试换个级数还是会卡。」然后给她一个 60 秒能做的替代动作——只点评她最后一句结论。
5. 她写完终稿。系统用问句核对 5 个要点：「你有没有明确写出『由莱布尼茨判别法』？」「∑1/√n 发散这一点，你引用了哪条现成结论？」——不给她标准答案。
6. 最后她用自己的话答五问，写下 3 条规律和一张自检卡；系统再给一道变式题（把 1/√n 换成 1/n²）。

老师第二天在看板上看到：小林这题用了 2 次提示、卡在「极限为 0 的依据」；全班 60% 的人卡在同一个点。下周上课，老师用 5 分钟集中讲这一点。

## 5. 三种真实使用场景

| 场景 | 什么时候用 | 怎么用 | 产品重点 |
|---|---|---|---|
| 课后作业卡住 | 晚上 8–11 点，手机 | 单题 15–25 分钟，边写边被追问 | 提示别太贵、别直接给答案、草稿不丢 |
| 考前复习 | 考试前 1–2 周，连续刷题 | 按知识点选题，看自己的卡点 | 选题效率、错题回顾、变式题 |
| 课堂/答疑课 | 老师投影或学生自带设备 | 老师演示一道题的全过程；或学生课上做 | 演示模式、教师看板实时性 |

> 这些场景是**待罗老师确认的假设**，不是拍脑袋定论。访谈提纲见 [../02-调研/03-罗老师访谈提纲与待确认问题.md](../02-调研/03-罗老师访谈提纲与待确认问题.md)。

## 6. AI 能给什么、不能给什么

| 能给 | 不能给 |
|---|---|
| 定义原文、定理名称、符号含义 | 完整证明 |
| 你这步「对/不对」的判断（锚定你的原话） | 最终结论、最终答案 |
| 方向类型（反证/构造/放缩） | 具体构造（如「取 δ=ε/5」） |
| 一次一步的局部提示 | 编号步骤、证明骨架、表格 |
| 大白话解释（每题最多 2 次） | 替你写、替你补全 |
| 完成度反馈（5 个要点你覆盖了 5 个） | 内部「关键要点」的原话转述 |

## 7. 老师看到什么

不是「监控屏幕」，而是一张**班级体检表**：

- 完成率、谁还没做；
- 平均每题被提示几次（提示越多，说明这题/这个知识点越难）；
- 卡点知识点 Top5（下周上课讲什么，有依据了）；
- 点开某个学生：每一步写了什么、哪一步被标可疑、用了几次提示、是否独立完成；
- 题库审核：老师审核过的题才放给学生；
- 一键导出 CSV/Excel，给论文或教研用。

## 8. 常见疑问（FAQ）

**Q1：这不会变成抄答案工具吗？**
A：AI 的回复被三道闸门限制：提示预算（L1≤3/L2≤3/L3≤2/L4≤1）、关键步骤计数（一题最多透露 2 个关键步骤）、输出闸门（禁用词、长度、与参考证明重合度、异厂商复核）。原型里可以亲手点「我要完整证明」看它怎么拒绝。

**Q2：学生会不会故意乱点提示刷答案？**
A：提示用尽后只能被追问，不能继续升级；跨会话累计计数；教师端能看到「提示依赖」，论文里也算这项指标。

**Q3：老师是不是要花很多时间？**
A：日常只需看一屏看板；主要投入在**题库审核**（前期 50 题，之后每月约 10 题）。需求确认书把「教师每次 1.5 小时小任务」写进了风险应对。

**Q4：为什么不做拍照搜题？**
A：技术方案 v2.0 明确把「开放拍照问答」视作实验混淆变量：题目范围、输入方式、提示规则都会变，无法归因。需求确认书里「拍照上传自己的题」与「不做拍照识题」存在冲突，需要甲方/罗老师拍板。

**Q5：和豆包爱学有什么区别？**
A：豆包类产品核心是「答得快、答得全」；我们核心是「不答完、逼你写」，并沉淀教师审核的题目包和过程数据。模型可以换，这两项资产换不掉。

## 9. 一页流程卡（可直接截图发人）

~~~ text
登录入班 → 今日任务 → 选题
   → 读题（这题要证什么？）→ 拆题（几件事？）
   → 写一步 + 依据 → AI 只指第一个可疑 → 追问
        → 卡住才给提示 L1→L2→L3→L4（每级有次数上限）
        → 改写 → 再提交 …… 直到写完
   → 终稿核对（问句清单）→ 五问复盘
   → 3–5 条规律 + 自检卡 + 1 道变式题
   → 掌握度 / 复习建议 →（一个月后）复测
~~~

## 10. 术语小词典

| 术语 | 一句话解释 |
|---|---|
| 证明 | 用已知的定义、定理，一步步推出结论；每一步都要有依据 |
| 条件收敛 | 级数本身收敛，但把每项取绝对值后发散（比如 1−1/2+1/3−…） |
| 绝对收敛 | 连绝对值级数都收敛，比条件收敛更强 |
| ε-δ | 描述「无限接近」的严格语言：你给误差 ε，我能找到范围 δ |
| 判别法 | 判断级数/极限的现成定理，如莱布尼茨判别法、p-级数判别法 |
| 关键步骤 | 老师认为这道题必须写到的那几步（学生看不到原文，只能被问句核对） |
| 提示阶梯 L0–L4 | 从「只追问」到「示范一小步」的五级帮助，越往后给得越多，但有次数上限 |
| 覆盖度 | 学生终稿写到了几个关键步骤，≥80% 算完成 |
